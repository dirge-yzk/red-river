# プレイテスト 4回目のまとめと対応 (v1.2 の新機能)

## テストの方法

貯水池・観測井戸・河川からの浸透・設備の追加・できごと・評価メーター・用語集を入れたビルドで、AI テスター3人が遊びました (操作説明書だけを渡し、内部資料は読ませていません)。報告書は `round4/` にあります。

| テスター | シナリオ | 結果 | 難易度の感想 |
|---|---|---|---|
| r4-feature (新機能の確認役。初期資金 9,000) | 平年 | S (97%) | 2/5 (資金が多いので参考外) |
| r4-long | 長期の試練 (20ターン) | B (67%) | 4/5 |
| r4-arid | 乾燥地 | A (82%) | 3〜4/5 |

## 分かったこと

- 固まる・遅くなる現象は、3人とも一度もありませんでした (長期の試練 20ターンを含む)。煙テストも、右パネルを毎ターン数か所クリックする強化版で全シナリオ通っています。
- **観測井戸**は「推定の幅が季節ごとに狭まる」効果が目に見えて、調査 (概査 ±25%・試掘 ±8%) との使い分けも判断できました。乾燥地では「推定の実際の範囲」の数値表示が、調べる価値の判断に役立ちました。
- **貯水池**は、操作が説明どおりに動くことは分かりましたが、「放流しない場合と比べて良くなったか」は、テスターには分かりませんでした。簡易プレイヤーの測定でも、効果は小さめです (後述)。
- 雨水利用・再生水・高効率ポンプ・井戸の増強は、資金が潤沢な場合は元が取れず、効果を感じにくいという感想でした。ただし、この感想は資金 9,000 で始めた確認役のもので、通常のシナリオで資金が少ない場合の判断は、長期の試練と乾燥地では「使う判断ができなかった」でした。
- 評価メーターは、足を引っ張っている指標を見つけるのに使えました。

## 見つかった問題と対応

| 指摘 | 対応 |
|---|---|
| 評価メーターの右端の % が見切れる | 部品の幅を縮めた |
| 評価メーターの財政が「今の残高 ÷ 基準」で、序盤〜中盤に実際の最終結果より低く出る (A/83% → B/69% に見えた) | 「今のペースが続いた場合の最終残高」で見込むよう変更。テストを追加 |
| できごとが、起こる季節にならないと分からず、備える余地がない | 方針パネルに「来季の予告」を追加 (貯水池の操作や優先順位で備えられる) |
| 雨水利用・再生水が見つからない (市街地の区域タブにある) | 方針パネルの「流域全体の施設」に、どの施設がどの区域タブにあるかの案内を追加 |
| 貯水池スライダーの読み方が用語集にない | 用語集に追記 |
| 川から地下水への浸透の「良し悪し」「水の行き先」が分からない | 結果カードと用語集に、「川の水が減る代わりに、その分が地下水に加わる」と追記 |

## 簡易プレイヤーによる、設備の価値の測定 (設備を無料で最初から持っている場合の、総合点の平均の変化。30シード)

| シナリオ | 貯水池 | 観測井戸 (農地・湿地) | 雨水利用 | 再生水 |
|---|---|---|---|---|
| 平年 | +0.01〜0.02 | 0.00 | +0.03 | +0.04 |
| 渇水 | +0.01 | −0.01 | +0.03 | +0.05 |
| 乾燥地 | +0.01 | 0.00 | +0.03 | +0.03 |
| 長期の試練 | +0.01 | −0.04 | +0.02 | +0.07 |

簡易プレイヤーは貯水池の操作や観測のデータを使いこなせないので、人間が使えば違う可能性があります。ただし、貯水池は容量 5,000 に対して、渇水の期間は川の水そのものが足りず、貯められるのは雨の多い季節の余り水だけなので、元々の効果は小さめです。

## 残っている課題

- 貯水池の費用 (2,000) に見合う効果があるかは、人間の試遊での確認が必要です。効果が小さいと感じる場合は、容量を増やす・蒸発損失を減らす・費用を下げる、のいずれかで調整できます。
- 高効率ポンプ・井戸の増強は、揚水が多い場面でしか元が取れません。長期の試練などの終盤で効くかの確認が必要です。
- 浸透量と揚水量の関係 (汲みすぎると川の水が減る) は、グラフなどで見せたほうが分かりやすいかもしれません。
- 3回目と同じく、人間のプレイテストは未実施です。この回の修正 (来季の予告・財政の見込み・説明の追記) は、AI テスターで遊び直していません。
