## 3. 最終結果

  - 生活・産業用水の充足度 100%(×2)(供給28,392 / 需要28,392 WU)
  - 環境流水の達成度 94%(×2)(最低基準を満たしたのは10/12ターン)
  - 地下水の残存 37%(×1)(貯留量は開始時の37%、揚水コスト上昇1区域)
  - 財政の健全性 100%(×1)(最終残高4,883、基準3,500、最低残高800)
- 総合62%について: 画面には「総合は重み付き平均ですが、最も低い指標+25%を超えません」と書いてあった。単純な重み付き平均(私の計算)は約86%になる。地下水の37%+25%=62%と一致するので、地下水がランクを決めたと思われる(この対応は私の推測。画面に「上限が効いた」とは書かれていない)。
- 地下水の評価基準(画面の文言): 「終了時の貯留量が開始時の70%以上なら満点。何もしなくても自然な湧出で貯留量は減るため、その分は許容する。揚水コスト上昇が起きた区域ごとに減点」。
- 費用と収入: 用水収入9,402 / 費用8,319(内訳: 調査400 / 建設3,000 / 投資3,200 / 維持560 / 揚水1,159)。

## 4. 詰まった点・分かりにくかった点

- **優先順位の警告文(今季の方針タブ)**: ターン1の初期順位(農業→環境→生活)で出た警告は「今の順位では、生活・産業用水が最後に削られます。水が足りない年は生活・産業が真っ先に不足しやすい」。1文目と2文目が逆のことを言っているように読めた。見出しは「水が足りないときは、下の項目から削られます」なので、「最後(=リストの最下位)に置かれ、真っ先に削られる」という意味だと後から理解した。「最後に削られます」は誤解しやすい。
- **「環境流水」が優先順位の項目に入っている意味**: 説明文「環境流水は『取水したあとに下流に残る水』です。順位が高い用途から先に河川水を取り、環境流水を上位にすると、その分が先に下流へ確保されます」でようやく理解した。ターン1で環境を最下位にして基準割れしたのは、読んだ上での私の判断ミス(生活を最優先にしたかっただけ)。ただ、「1位へ」を押した直後に、環境が最下位になる副作用に関する警告は出なかった(警告が出ていたのは元の順位のときだけ)。
- **優先順位は春にしか変えられない**: 説明は画面にあった(「順位は年に1回(春)しか変えられず」)。ターン2(夏の渇水)で環境が53%になり、順位を変えたくても変えられなかった。分かってはいたが、ターン1の選択がその年の全4季節に響くことが、ターン1の時点では実感しにくい。
- **河川目標スライダー(%)の持ち越し**: 「割合(%)は次の季節にも引き継がれます」の意味が最初は分かりにくかった。実際、ターン3(秋)で農業が34%のまま残っていた。ターン12の冬に向けては農業0%が出ていた(需要0の季節)。次の季節で戻し忘れると不足に直結する。毎ターン上から確認した。
- **方針タブの縦スクロール量**: 情報が長く、スライダー・揚水上限・優先順位・行動費用が1画面に収まらない。毎ターンスクロールを繰り返した。
- **スライダーの精度**: クリックで%が決まるが、希望の値(例: 30%)ちょうどには合わせにくく、26%や35%になることがあった。画面に値が出るので確認はできた。
- **揚水の仕組み**: 「揚水は、河川水で足りない農業・生活産業の用水にだけ使われます」が重要な仕様だが、画面で気づくのが遅かった。河川目標を下げれば不足分が井戸で補われることを、ターン5で試してやっと確信した。
- **結果カードの「実績」と予報の関係**: 予報レンジに対し実績はほぼ範囲内に収まった。
- **誤クリック**: ターン1で市街地を選ぶつもりが地図の何もない所(x=470)をクリックして選択されなかった(自分の座標ミス)。画面の問題ではない。

## 5. 不具合に見える挙動

1. **市街地の流出係数の表示が動かない(不具合かどうかは分からなかった)**: 市街地タブの「流出係数 0.55」は、ターン1(開始時)、ターン5(1年目の浸透改善の後)、ターン12(終了時)のすべてで 0.55 のままだった。方針タブには「舗装で市街地の流出係数が年 +0.05 ずつ上がります」「浸透改善は流出係数を20%下げる」と書いてあるので、表示値が変わると思っていた。たまたま打ち消しあって同じ値になったのか、表示が更新されないのかは、画面からは分からなかった。
2. **「調査した区域の推定誤差が未調査より大きい」**: 学習目標4に「終了時の推定の誤差は、調査した区域で平均42%、未調査の区域で平均13%」とある。調査すれば幅が狭まる、という説明と逆に見える。調査後に揚水で貯留量が変わったことで、推定が実際から離れたのだと思う(推測。画面からは確認できない)。農地は調査時点の推定15,787(±25%)で、終了時の推定は実際より+47%も高かった(幅±25%を超えた)。
3. **推定を信じた結果、閾値を気づかないまま下回った**: ターン8で農地の「今季末の推定貯留量 約7,849(閾値4,000)」、ターン9でも「約6,824」と表示され、余裕があると見えていた。しかしターン12の開始時には農地に「揚水コスト上昇中(恒久)」が出ていて、実際はすでに閾値を下回っていた。推定が実際より大きく表示され続けたためで、「操作と表示の食い違い」というより、推定誤差の問題。
4. その他の操作と画面の食い違いは見つからなかった。クリック→スクリーンショットの確認で、選択・確定は想定通りに動いた。

**4 / 5(やや難しい)**

- 根拠:
  - 市街地の需要は年+20%で増える(生活の需要は春 1,800→2,160→2,592、夏 2,640→3,168→3,802)。その一方で、渇水の夏と少雨の春・秋が来る。
  - 最初のターンで資金が1,800しかなく、浸透改善(1,200)・調査(200)・井戸(1,500)・灌漑(2,000)を同時にはできない。優先順位を考える余地はあるが、序盤は「どれを先にやるか」が重い。
  - 私はターン1・2で環境流水の基準割れ(79%・53%)を出した。その後は10ターン連続で基準を満たしたが、最終ランクはCだった。
  - 「何をすれば総合が上がるか」の理由(地下水が足を引っ張る)は、最終画面を見るまで分からなかった。
- 情報が足りていたか:
  - 良い点: 今季の見込み(取水点の利用可能量・取水目標・下流へ流れる量・環境基準)、各季節の需要見込み、「来年の同じ季節の需要」。これらは判断に使えた。
  - 足りなかった点: 地下水の指標(開始時比)が、プレイ中に画面のどこにも出ない。最終結果で初めて37%と知った。
- 選べる行動の数: 1ターンに主要行動1つ(概査 / 試掘 / 井戸 / 浸透改善 / 灌漑)+優先順位(年1回)+目標% + 揚水上限。数としては適切で、迷いすぎることはなかった。

## 8. もう一度遊ぶなら

- ターン1から 生活→環境→農業 の順位にする(環境基準割れを避けるため)。
- ターン1・2は浸透改善より、先に農地の概査(200)と井戸(1,500)を急ぐ。夏の渇水に間に合わせたい。市街地の浸透改善は、井戸の後で良いと思う。
- 揚水は「推定の持続的揚水量」を目安に、閾値に近づく前に止める。私は農地の井戸を毎回上限(1,650)近くまで使い、結果的に農地の貯留が閾値を割った。
- 最終残高は4,883も余った。財政は基準3,500で100%なので、余った資金は農地の浸透改善(1,200)や、早めの試掘(800)で地下水の判断精度を上げることに使えた。
- 理由: 総合は「最も低い指標+25%」に縛られるので、地下水を守る方に力を割いたほうが、他を犠牲にしなくてもランクが上がるから。ただし、どの程度揚水を抑えれば70%に届くのかは、画面からは分からなかった。

## 10. 遊びごたえ

- 工夫した分だけ結果は良くなったと思う。ターン1・2(何も考えずに優先順位を決めた時期)は環境が基準割れしたが、ターン5で優先順位を変えて井戸で補う方式に変えてからは、環境と生活が安定して100%になった。
- ただし、最終結果は「地下水」という、プレイ中に見えない指標で頭打ちになった(総合62%)。工夫が成績に届く経路が、画面からは分かりにくい。
- 何もしなくても良い結果になるか: 試していないので分からなかった。ただ、ターン1の初期設定(農業→環境→生活)のままだと、生活産業が真っ先に削られるという警告が出ていたので、そのままでは良い結果にならないと思う(これは画面の警告から推測)。

### 補足: 「地下水の指標が不当に低くならないか」について

- 事実: 画面の説明では、地下水は「開始時の70%以上なら満点」で、自然な減少分はあらかじめ許容される、とある。私の結果は37%で、揚水8,904 WU・農地の揚水コスト上昇1区域だった。
- 事実: 学習目標2に「涵養1,764 WU に対し、揚水8,904 WU を汲み、河川へ15,389 WU が湧き出しました」とある。湧出が揚水の約1.7倍ある。
- 事実: 渇水の夏(T2、T6)や少雨のターン(T9、T11)は、農業を100%にするには井戸を上限近くまで使う必要があった。揚水を我慢すれば農業と環境のどちらかを落とすことになる。
- 分からなかったこと: 揚水を全くしなかった場合の地下水が何%になるのか、70%に届く現実的な揚水量はいくらか。画面には出なかったので、地下水の指標が「不当に低い」かどうかは判断できなかった。
- 感想: 少なくとも、「市街地拡大」で需要が毎年+20%増える設計と、地下水70%の基準を同時に満たす道筋は、私には見えなかった。総合が「最低指標+25%」に縛られるので、地下水が37%だと、他が全部ほぼ満点でもCになる。このため、地下水の基準は厳しく感じた。
- 「優先順位の説明」と「1位へボタン」について: 「1位へ」は1回のクリックで項目を一番上に移せて、使いやすかった(ターン1で生活産業を一番上へ)。一方、2位に動かしたいときは「1位へ」が使えず、▲▼を使った(環境を3位→2位)。説明文(「順位が高い用途から先に河川水を取り、環境流水を上位にするとその分が先に下流へ確保される」)は、読んで理解できれば役に立ったが、ターン1では環境を最下位にしてしまった。環境流水が「用途」と同列に並ぶ意味は、1回読んだだけでは理解しきれなかった。

### 補足: 市街地の拡大(需要増・舗装)の意味と対策は画面から分かったか

- 分かったこと: 方針タブに「生活・産業の需要は年に20%ずつ増え、舗装で市街地の流出係数が年+0.05ずつ上がります(流出係数が高いほど、降水が地面にしみ込まず川へ流れ出し、地下水の涵養が減ります)」と明記されていた。需要増は、「来年の同じ季節の需要 X(今季 Y)」で毎ターン数字が見えた。対策として、市街地タブの「浸透改善(流出係数を20%下げる、平年の降水で年約1,153 WU が浸透・涵養へ回る目安)」「灌漑効率の改善(農業の需要を20%減らす)」「井戸」が選べることも分かった。
