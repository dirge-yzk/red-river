# 第5回 AIテスト (固定盤面の画面)

対象: v1.2.1 の画面 (固定盤面・スクロールなし・ページ送り・観測計器)。テスター2名 (チュートリアル 4 ターン / 長期の試練 8 ターン)。報告書は `round5/`。

## 指摘と対応

| 指摘 | 対応 |
|---|---|
| 優先順位切替器の右の接点ラベルが盤の端で切れる | 略称の接点をやめ、項目名を完全な語で表示する順位セレクタ (▲▼) に変更 |
| マニュアルの「前へ・次へ」の位置がページごとに動く | ページ枠を固定の高さにして、押しボタンの位置を固定 |
| ヒントが「地図の中流農地をクリック」と言うが、すでに選択済み | ヒントの文面を修正 |
| 土壌水分が何に効くか・「河川水の不足」の灯の意味・ポンプの色帯の境目・財政メーターの基準が不明 | マニュアルに追記 |
| 最終報告書の「7.3E-012 WU」 | 「0 WU」と表示 |
| ヘッダーの残高と設備ページの「自由に使える資金」が食い違う (差は今季の交付金) | 文言を「使える資金 (残高+交付金)」に変更 (表示は残す) |
| 同じ情報の重複 (調査状態・環境流水の見込みなど) | 一部は意図した別の見せ方 (★=今季の予定 / ランプ=実施済み) のため据え置き |

## 未対応・判断待ち

- 設備ページのボタンの並びが区域ごとに変わる。
- 流量メーターの目盛りの数字に針が重なる瞬間がある。
- 評価・財政ページの評価メーターは、最終報告書と同じ数字になる (途中経過の見込みとして残している)。
