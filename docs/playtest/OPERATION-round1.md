# ゲームの操作方法

あなたは、ある水資源管理ゲームの**プレイヤー**です。このゲームについて知っているのは、このファイルに書かれた「操作方法」と、**ゲーム画面に表示される内容だけ**です。

## 守ること

- ゲームの内部資料・ソースコードは**読まないでください**。具体的には `/home/user/WaterGame` 以下、`app/` の中のファイル、`work-*/app.log`、`*.dll` を開いたり検索したりしないこと。画面から得た情報だけで判断して遊びます。
- 使ってよいのは、`/home/user/playtest-kit/ui.sh`(画面操作のヘルパー)、スクリーンショットの画像、報告書を書くためのファイル操作だけです。
- 分からないことは、**分からなかったと報告書に書いてください**(推測で埋めない)。

## 起動・操作コマンド

作業ディレクトリは `/home/user/playtest-kit` です。`DN` は他のプレイヤーと重ならない番号です(指示された番号を使うこと)。

```sh
cd /home/user/playtest-kit
DN=101 ./ui.sh start --scenario 平年 --seed 101   # 起動 (約10秒かかる)。オプションは指示に従う
DN=101 ./ui.sh shot                               # スクリーンショットを撮る。画像のパスが表示される
DN=101 ./ui.sh click 990 779                      # 画面上の座標 (X,Y) を左クリック
DN=101 ./ui.sh scroll 990 400 10                  # (X,Y) の上でホイールを下へ10回 (負の数で上へ)
DN=101 ./ui.sh stop                               # 終了
```

- 画像は、Read ツールでパスを指定すると見られます。**画像のピクセル座標が、そのままクリック座標**です(画面は 1280×860)。
- クリックのあとは自動で1秒待ちます。**クリックするたびにスクリーンショットを撮って結果を確認**してください。画面が思った通りに変わらないことがあります。
- 起動オプション: `--scenario <名前>`(シナリオ)、`--seed <整数>`(同じ数なら同じ展開になる)、`--skip-intro`(遊び方の画面を省く)。

## 画面の見かた・操作のしかた

ゲームのウィンドウは、画面の左上 (10,10) から 1180×800 の大きさで表示されます。

- **上の帯(ヘッダー)**: 今のターン、気象カード、降水予報、残高などが表示されます。操作はできません。
- **左側の地図**: 色のついた四角が区域です。**区域をクリックすると選択され**、右パネルが、その区域の内容に切り替わります。
- **右側のパネル**: 上に2つのタブがあります。左が「今季の方針」、右が選択中の区域名です。クリックで切り替えます。
  - パネルの内容が長いときは、**パネルの上でホイールを回す**(`scroll`)と上下にスクロールします。
  - **スライダー**: 横線(トラック)の好きな位置をクリックすると、その位置の値になります。つまみをドラッグする必要はありません。
  - **ボタン**: 灰色は選択肢、青色は主なボタンです。押せないボタン(薄い色)もあります。
  - **▲ ▼ ボタン**: 項目の並び順を上下に動かします。
- **右下の青いボタン「この方針で季節を進める」**: ほぼ (990,779) にあります。これで方針を確定し、季節が進みます。
- **結果の画面**: 季節が進むと、画面の中央に白いカードが重なって表示されます。長いときは、カードの上でホイールを回すと中が動きます。カードの**下に固定された青いボタン**(「次の季節へ」「最終結果へ」)を押すと閉じます。カードの大きさで、ボタンの高さが変わります。**必ずスクリーンショットでボタンの位置を確かめてから**押してください。
- **最終結果の画面**: 一番最後に、結果と振り返りが出ます。下のボタンを押すと**新しいゲームが始まります**。報告書に書く内容を、**押す前に**すべて読み取ってください。
- 起動直後は「遊び方」の画面が出ます。読んでから「はじめる」を押してください。

## 報告書

プレイが終わったら(または詰まって進めなくなったら)、`/home/user/playtest-kit/reports/<あなたの名前>.md` に、次の内容を日本語で書いてください。事実と、あなたの感想・意見を**分けて**書くこと。

1. **条件**: シナリオ、シード、プレイした範囲(何ターンまで)。
2. **ターンごとの記録** (表): ターン / 季節と気象カードの予報 / 設定した方針と主要行動 / 結果 (農業・生活産業の充足率、環境流水、残高など) / そのとき考えたこと・意図。
3. **最終結果**: ランク、総合点、各指標の評価、学習目標の振り返りの要点。
4. **詰まった点・分かりにくかった点**: 画面名・操作・何が分からなかったか・どう解決したか(または解決できなかったか)。誤クリック、表示の見切れ、文言の意味不明、ボタンの位置の分かりにくさなども含む。
5. **不具合に見える挙動**: 画面の表示と、あなたが操作した内容が食い違った箇所(あなたの操作 → 実際に起きたこと → 期待したこと)。
6. **難易度の感想**: 5段階(1: 易しすぎる / 3: ちょうど良い / 5: 難しすぎる)と、その根拠(どのターンで何が起きたか)。選べる行動の数や、判断に必要な情報が足りていたかも書く。
7. **ほしい機能・改善案**: 遊んでいて「これがあれば」と思ったこと(優先度つき)。
8. **もう一度遊ぶなら**: やり方を変えるか、その理由。
