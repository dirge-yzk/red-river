## 3. 最終結果
- **ランク A、総合 83%**。プレイ時間 2.6 分 (目安 15〜25 分)、方針決定の平均 30 秒 (目安 45〜90 秒)。
- 各指標: 農業用水の充足度 71% (供給 6,850 / 需要 9,600 WU)、生活・産業用水 100% (6,500 / 6,500)、環境流水の達成度 86% (最低基準を満たしたのは 1/4 ターンのみ)、地下水の残存 100% (貯留量は開始時の 97%、揚水コスト上昇 0 区域)、財政の健全性 100% (最終残高 2,756、最低残高 1,500)。重みは全指標 ×1。
- 費用: 用水の収入 2,396、費用の合計 2,140 (調査 1,000 / 建設 1,000 / 投資 0 / 維持 80 / 揚水 60)。
- 学習目標の振り返りの要点:
  - 1 水収支: 降水 67,518 WU のうち、蒸発散 85%、用水供給 20%、下流端からの流出 12%、貯留の増減 −17%。収支の残差は最大 7.3E-012 WU。
  - 2 地下水のストック性: 貯留量は開始時の 97%。涵養 5,537 WU に対し揚水 500 WU、河川への湧出 7,020 WU、河川から地下水への浸透 885 WU。
  - 3 トレードオフ: 農業 71%、生活 100%、環境流水は 1/4 ターンのみ満たした。最も満たせなかったのは農業 (71%)。最後の優先順位は「生活 → 農業 → 環境流水」。
  - 4 情報の価値: 調査は 2 回、調査費 1,000。終了時の推定誤差は調査した区域で平均 6%、未調査の区域で平均 24%。
  - 5 不可逆性: 閾値を下回った区域はなく、揚水費の合計は 60。
- 地下水貯留量の推定と実際のグラフ (3 ページ目): 上流山地は ±43% のまま (終了時の推定は実際より +48%)、中流農地は第 1 ターンに調査して +6%、市街地は ±43% のまま (−13%)、下流湿地は ±45% のまま (−13%)。

## 4. 詰まった点・分かりにくかった点 (新しい画面の使いやすさ)

### (a) 画面のどこに何があるか迷った所
- 開始直後は「運転」タブが開いていて、ヒント枠 (左下の黄色い枠) は「地図の『中流農地』をクリックして設備ページで『概査』を押す」と指示していた。しかし中流農地はクリックしなくても最初から黄色い枠で選択済みになっていて、「設備」タブを押すだけで「中流農地 設備台帳」が開いた。どの区域が選択中かは、地図の黄色い枠と設備台帳の見出しで分かったが、最初は「まだ選んでいない」と思って迷った。
- 区域クリックで「設備」ページに切り替わる動作は、ゲーム終了後に上流山地をクリックして確認できた (ちゃんと切り替わった)。ただ、選択中の区域は黄枠だけで示される。
- 運転の画面は縦に 3 つの帯 (予報と見込み / 河川からの取水 / 揚水ポンプ・貯水池) が並んでいて、順番は分かりやすい。ただ、「環境流水」を決める設定器が「河川からの取水」の帯の中にあり、環境流水の見込みの灯は上の「予報と見込み」の帯にある。操作するダイヤルと結果の灯が別の帯にあり、視線を往復させる必要があった。
- 残高が出る場所が 3 つある (ヘッダー・設備の「資金」・運転日報の財政)。
- 「運転開始」ナイフスイッチは右下で見つけやすかった。運転日報のナイフスイッチ (「次の季節へ」) は中央下で位置が違うため、毎回スクリーンショットで確認してから押した。

### (c) 文字が切れている・重なっている・読めない所
- **優先順位切替器の右の接点ラベルが切れている**: 「生>農>環」が右端 (盤の端 x≈1190) で切れ、「生>農>」までしか見えなかった。実際に選んだ順位 (生>農>環) は指針が右を向いていることと、最終報告書の「生活→農業→環境流水」で確認できた。画面上の文字だけでは切れて見える。「農>生>環」(左の接点) も盤の円の縁に近く、一部が文字盤にかかっていた。全ターンで同じだった。
- 運転日報の 3 ページ目が表示されるたびに、背後の盤の右側 (運転の盤) が半透明の暗幕で隠れるため、「運転日報の中でどのタブを開いていたか」が分からなかった (意図的な暗幕だと思う)。
- ヒント枠 (左下) は、日報を開くと日報の下に隠れて文字が途切れる。日報を開いている間は読めないので、日報を閉じてから読み直した。
- ダイヤルの目盛りの数字 (例: 「4.5k」「6.8k」「3.8k」) に、赤や黄の針が重なって読みにくい瞬間があった (夏の取水点の流量メーターで「5.3k」の近くに針が重なる、下流の流量メーターで「0.8k」に赤針が重なるなど)。
- 地図の小さい計器の数字 (「0 1000」「0 2000」) は小さく、針に重なる。スクリーンショットでは読めたが、実際の画面でも小さいと思う。
- 運転の盤の「環境流水: 降水が少ないと基準割れ」の文が 2 行に折り返し、「割れ」だけが 2 行目に出た (読めるが見栄えが悪い)。
- 最終報告書 2 ページ目の「7.3E-012 WU」は科学表記で、意味が分かりにくい (「差はほぼ 0」の意味だと思うが、説明は無い)。
- 最終報告書 3 ページ目の小さなグラフは、縦軸・横軸の目盛りが無く、青と赤の線の凡例は上の小さい文字の説明だけ。グラフから値は読み取れなかった (考察の文章で値が分かる)。
- 地図の区域の地下水の水位計の「右の青いかっこ」は、小さいうえ、色が薄いと見えにくかった (中流農地の夏は見えたが、上流山地は見分けにくい)。

### (d) 計器の読み方が分からなかった所 (マニュアルで分かったか)
- **土壌水分計**: 針が乾 (赤)・適 (緑)・湿 (青) のどこかで読める。マニュアル 2/5 に「保水容量に対する割合」とある。分かった。ただ、上流山地・市街地・下流の土壌水分は冬に 20% / 21%、秋に 0% まで下がるのに、このゲームで何を意味するか (農業用水の充足率に響くのか、地下水への涵養に影響するのか) は、マニュアルにもヒントにも書かれておらず、分からなかった。
- **地下水の水位計**: 青いかっこ (推定の幅)、赤い線 (閾値) はマニュアル 2/5 で分かった。下の数字 (例: 16500) の単位は画面に書かれておらず (WU だと思うが、確認できなかった)。
- **持続的揚水量メーター**: マニュアルで「黄の針=350、緑の針=800 が評価の境目、青い弧が推定の幅」と分かった。ただ、メーター下の数字 (763) は、概査後に「持続的揚水量の推定 約 763」と運転日報に出た値と同じと推測した (確認はしていない)。
- **運転の予報メーター**: 降水予報は雨量計、取水点の流量・下流の流量は指針式。「青い印 = 見込み範囲、針 = 中央の見込み、黄/赤の短い針 = 基準」と、マニュアル 1/5 を読んで分かった。読む前は、黄色い針 (取水目標の合計) と赤い針 (環境流水の最低基準) の違いが分からなかった。マニュアルを見れば分かった。
- **河川水の不足の灯**: 「河川水の不足 (降水が少ない側): 農業 385 WU」と出た意味 (秋、ポンプ 500 の状態で灯が点いたまま) は、ポンプで補える量を引いた後なのか、引く前なのか、画面からもマニュアルからも分からなかった。実際は農業 96% まで満たせたので、引く前の数字だったと推測するが、確かめられなかった。
- **揚水ポンプのダイヤル**: 目盛りは「0 / 900 / 1800」だけで、緑・黄・赤の色帯が何 WU までかは数字で読めなかった。マニュアル 2/5 に「緑=下限以下 (確実に安全)、黄=不確かな領域、赤=確実に超過」とあるので、概査の推定 (763 ±25%) から 500 を選べば緑だろうと考えて 500 にした。針が緑の領域にあることは目で確認できたが、境目の数字は読めなかった。
- **優先順位切替器**: 「農>環>生」などの略記は、マニュアル 1/5 の「農=農業用水、環=環境流水、生=生活・産業用水」で分かった。ただ、略記の意味は切替器の近くには書かれていない (遊び方の画面には書かれていない)。
- **環境流水の達成度 95% / 85% / 66% の計算**: 「実績 1,906 / 計画 2,000」から 95% になる、という計算は、日報の数字を見れば分かった。
- **総合点の計算**: 総合 83% は、「重み付き平均 (0.6) と最も低い指標 (0.4)」の混合とあるので、0.6 × (71+100+86+100+100)/5 + 0.4 × 71 = 0.6 × 91.4 + 28.4 = 83.2 と合うことを確認できた。マニュアルを見れば分かった。

### (e) クリックしても反応しない・意図と違う操作になった所
- 反応しなかったクリックはなかった。タブ、押しボタン、ダイヤル、切替器、ナイフスイッチ、ページ送り、区域クリックはすべて意図通りに動いた。
- 意図とずれた所:
  - ダイヤルの値は、クリックした角度から計算されて 50 刻みに丸められるようだった。60% (2,600) を狙って 2,600 に、40% (1,760) を狙って 1,750 になった。ぴったりの値を出すのは難しいが、必要な精度は十分だった。
  - 秋に農業バルブを自動で引き継ぎ (夏の 40% のまま 950) 、需要が 2,400 に変わったため、実際の値は 1,750 → 950 に変わっていた。「開度 (%) が引き継がれる」とマニュアル 1/5 には書かれているので仕様だが、気付かずに放置すると意図と違う値になる。
  - 冬は農業バルブが「今季は休止」で操作できず、目盛りが消える。分かりやすかった。
  - 優先順位切替器は春だけ操作可能。夏以降は「(固定)」と出るので、分かりやすかった。右のラベルが切れているのに、そのあたりをクリックしても反応した (切れた文字の位置のクリックでも切り替わった)。
  - 「設備」タブを開いたあと「運転」タブに戻っても、ダイヤルの設定は保持されていた。
  - 運転日報の「前へ / 次へ」ボタンは位置が毎回同じで、マニュアルのページ送りのように動くことはなかった。

## 5. 不具合に見える挙動
- 優先順位切替器の右の接点のラベル「生>農>環」が盤の端で切れている (操作 = 画面を見るだけ → 実際 = 「生>農>」までしか見えない → 期待 = 全文が見える)。
- 運転日報 1 ページ目の冬ターンで、農業用水の充足率が「100%」と出る (需要 0 で供給 0 の場合の扱い)。仕様だと思うが、「0 ÷ 0 = 100%」であることの説明は無く、分かりにくい。
- 最終報告書の「7.3E-012 WU」の科学表記 (期待: 「0」または「ほぼ 0」)。
- 春のターンで、ヘッダーの残高 (1,500) と設備ページの「自由に使える資金」(2,500) が食い違って見える (交付金 1,000 の加算前後)。

## 6. 難易度の感想
- **2 (やや易しい)**。根拠: 最後まで A ランク (83%) で、深く考えなくても大きく失敗しなかった。ヒント枠が毎ターン次の行動 (概査 → 井戸 → ポンプ) をほぼ指示していて、その通りに動くだけで 4 ターンが終わった。1 ターンの所要時間も短く (方針決定の平均 30 秒)。
- 一方、夏と秋の環境流水と農業のトレードオフ (夏: 農業 40% / 環境 85%、秋: 農業 96% / 環境 66%) は、どちらも「完全には満たせない」という手応えがあり、ここは考える余地があった。
- 選べる行動の数: 設備ページで 1 ターンに選べる行動は 5〜7 個 (概査・試掘・井戸・浸透改善・観測井戸・灌漑効率・節水キャンペーン)。多すぎず、チュートリアルには適当。ただ、費用が払える範囲 (残高 2,500〜3,000) なので、高額な行動 (灌漑効率 2,000) を選ぶかどうかという迷いは少なかった。
- 判断に必要な情報は足りていた。ただし、夏の判断では「予報の幅の下側を見るべきか、上側を見るべきか」の目安が画面に無く、自分で決める必要があった (チュートリアルでは仕方ないと思う)。

## 8. もう一度遊ぶなら
- 夏の農業バルブを 40% ではなく 60% 程度にする、または秋のポンプ上限とバルブを調整して環境流水を 1,500 に近づけるなど、環境流水も満たす配分を試したい。理由: 今回は農業 71% と環境流水 86% という低い指標が残ったため (総合の 40% は最低指標で決まるので、最も低い指標を上げるのが効く)。
- 春に優先順位を変えずに (農>環>生 のまま) 進めて、環境流水と生活用水がどうなるか比較したい。理由: 今回は指示通りに「生>農>環」にしたが、変えなかった場合との差が分からないため (この点は今回は検証していない)。
- 概査を春ではなく別の区域でも試す。理由: 未調査の区域は終了時の推定誤差が平均 24% だったため、調査の価値をもう少し比べたい。

## 9. 判断に使えた表示・使えなかった表示
- **使えた**:
  - ヒント枠 (左下の黄色い枠)。毎ターンの助言が具体的で、最もよく使った。
  - 運転ページの「予報と見込み」の 3 つのメーターと、メーター下の数字の範囲 (「617〜2,600」など)、環境流水の灯 (緑/黄/赤)。ダイヤルを回した直後に灯と範囲が更新されるので、操作の効果をすぐ確かめられた。
  - ダイヤルの下の桁カウンタ (実際の WU の値)。
  - 運転日報 2 ページ目の「河川水の流れ」(取水点の利用可能量 − 農業 − 生活 + 湿地からの流入 = 下流の流量)。計算が追えて、なぜ環境流水が足りなかったかが分かった。
  - 設備ページの「資金」の桁カウンタ (今季の交付金 / 自由に使える資金 / 選んだ行動の費用 / 行動後の資金)。
  - マニュアル 1/5 〜 3/5 (予報メーター、取水バルブ、ポンプ、各行動の費用と効果)。
  - 概査・試掘の結果の表示 (推定の幅が ±45% → ±25% → ±8% に狭まる)。
  - 最終報告書の指標の表と、学習目標の振り返り。
- **使えなかった / 意味が分からなかった**:
  - 土壌水分計 (何に効くのかが分からず、判断に使わなかった)。
  - 河川水の不足の灯の数字 (ポンプとの関係が分からなかった)。
  - 運転日報 3 ページ目の区域ごとの水収支の表 (降水・地表流出・浸透・蒸発散・涵養・河川浸透・揚水・土壌変化)。数字は多いが、判断には使わなかった。
  - 最終報告書 3 ページ目の推定と実際のグラフ (軸が無く、考察の文章の方が分かりやすかった)。
  - 「評価・財政」タブの途中経過のメーター (最終報告書と同じ内容)。見たが、方針決定には使わなかった。
  - 上流山地・市街地・下流湿地の地下水・持続的揚水量のメーター (操作できる行動が少なく、このシナリオでは判断に使わなかった)。

## 10. 遊びごたえ
- 工夫した分だけ結果が良くなったかは、**はっきりとは分からなかった**。比較実験 (別の設定で同じシードを遊ぶ) をしていないため。
- 何もしなくても良い結果になったか: 最初の設定のまま (農業 100%、生活 100%、環境流水 最低基準) 進めた場合の結果は試していないので、分からない。ただ、夏の需要 4,400 + 2,200 に対して取水点の見込みが 4,074〜5,912 だったので、何もしないと農業・環境流水のどちらかが大きく崩れたと推測できる (推測であり、確認はしていない)。
- 手応えがあった所: 夏のバルブの絞り方 (農業 40% / 環境流水 85%) と、秋のポンプ上限の選び方 (環境流水 66% になった)。数字がすぐに灯とメーターに反映されるので、試行錯誤はしやすかった。
- 物足りなかった所: 冬は何もしなくても全指標 100% になる。また、チュートリアルでは「井戸を建てる」「ポンプを開ける」がヒント通りに進むので、自分で考える場面が夏の配分以外では少なかった。
