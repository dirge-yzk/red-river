## 3. 最終結果

- ランク A(総合 84%)
- 指標ごとの評価(すべて重み ×1)
  - 農業用水の充足度: 100%(供給 22,100 / 需要 22,100 WU)
  - 生活・産業用水の充足度: 94%(供給 18,404 / 需要 19,500 WU)
  - 環境流水の達成度: 100%(最低基準を満たしたのは 12/12 ターン)
  - 地下水の残存: 100%(貯留量は開始時の 139%、揚水コスト上昇 0 区域)
  - 財政の健全性: 59%(最終残高 1,171 / 基準 2,000、最低残高 406)
- 総合は重み付き平均だが、最も低い指標 +25% を超えない、と画面に書かれていた。
- 費用と収入: 用水の収入合計 9,401 / 費用合計 12,030(調査 2,400 / 建設 4,500 / 投資 4,400 / 維持 640 / 揚水 90)。
- 学習目標の振り返り(要点)
  1. 水収支: 降水 329,853 WU の配分は、蒸発散 64%、用水供給 12%、下流端からの流出 14%、貯留増減 10%。収支の残差は最大 5.9E-012 WU。
  2. 地下水のストック性: 貯留量は開始時の 139%。涵養 39,902 WU に対し揚水は 750 WU、川への湧出 22,341 WU。
  3. 配分のトレードオフ: 農業100%、生活・産業94%、環境は 12/12 ターンで最低基準を満たした。最も満たせなかったのは生活・産業用水。最後の優先順位は「生活・産業用水 → 農業用水 → 環境流水」。
  4. 情報の価値: 調査は 6 回、調査費 2,400。終了時の推定の誤差は平均 6%。
  5. 不可逆性: どの区域も閾値を下回らず、揚水コストは上昇しなかった(揚水費の合計 90)。
- そのほか表示されたもの: 地下水貯留量の「推定(青)と実際(赤)」の小さなグラフ4枚(区域別)、区域ごとの調査時期のコメント(上流は第12ターンに初調査、市街地は第5ターン、下流は第10ターン、農地は第1ターン)、ターンごとの推移表(農業充足・環境達成・最低基準・期末残高)、「全ターンで収支が一致」。

## 4. 詰まった点・分かりにくかった点

事実:
1. **井戸の建設ボタンが出る条件が分からない**(各区域タブ)。第1ターンの中流農地には「井戸: 未建設」とだけあり、井戸ボタンがない。概査を済ませた次ターンから「試掘・揚水試験」「井戸を建設する」が現れた。「概査をしないと井戸は建てられない」という説明は画面になかった。上流・下流・市街地でも同じ(概査後に出る)。
2. **概査と試掘・揚水試験の違い**が、選ぶ時点では分からない。ボタンには費用(200 / 800)しか書かれていない。精度(±25% / ±8%)は、実行した後の結果カードで初めて分かった。
3. **揚水上限スライダーが「今季の方針」タブではなく、各区域タブの中**にある。方針タブで揚水を設定できるとは思わなかった。主要行動の途中にあり、スクロールしないと見つけにくい。
4. **揚水上限の初期値が変わる**: 農地は 800 → 750 に、市街地は 500 → 550 と、持続的揚水量の推定値に合わせて自動で動いているように見えた(これは推測)。説明はない。井戸の「能力 1,800 WU/季節」と「持続的揚水量 約775」の関係も、文章だけでは掴みにくかった。
5. **配分優先順位の影響が事前に分からない**。第5ターンで農業を生活・産業より上にしたまま第6ターンの渇水に入り、生活・産業が 50% になった。結果カードにも「優先順位の低い用途から足りなくなった」とは出ない。説明が出るのは最終結果の学習目標3だけ。順位の入れ替え機会も年1回の春しかないので、気づくのが遅れる。
6. **「前季の実績: 取水点の利用可能量」**は前の季節の値で、今季の予報降水との関係が分からない。今季に取れる水量の見込みがないため、需要の合計が足りるかどうかを事前に判断できない(例: 第6ターン。需要 農業4000+生活2200+環境1800=8,000 に対し前季の利用可能量は 6,578)。
7. **用水の単価・揚水費・維持費の算定方法が画面にない**。収入 875 や 1,350 は結果カードで初めて見る。感想: 事前に見積もれると計画しやすい。(参考: 表示された数字から計算すると、農業 0.2 / 生活・産業 0.25 per WU のように見えたが、画面に書かれていた事実ではない。)
8. **「今季に自由に使える資金」は選択した主要行動の費用を引かない**(残高と同じ数字のまま)。選ぶと残高との差が分からない。
9. **表示の見切れ**
   - 選択した主要行動ボタンの文言が欄外で切れる: 「✓ 浸透改善に投資する (費用 1,200) (クリックで取」。
   - 地図カードの「★今季: …」表示が長いと折り返され、取水点の丸や枠にかぶる(「★今季: 市街地・工業地域で概」「★今季: 灌 / 漑効率改善」)。
   - 結果カードの末尾の学習目標の文が、スクロール前は途中で切れて見える(スクロールバーは細く、気づきにくい)。
10. **「残差」が `2.3E-012`、`-3.6E-012`、`0.0E+000` のような指数表記**で出る(結果カード「流域全体の水収支」)。意味が分かりにくく、学習目標1の説明の邪魔になる。
11. **最終結果の「ターンごとの推移」表**には農業充足・環境達成・最低基準・期末残高しかなく、生活・産業の充足率の列がない。生活・産業が 50% に落ちた第6ターンが表に出ず、「環境達成」「農業充足」が全部 100% で、どのターンが問題だったか分からない。
12. **最終結果の下のボタンは4つとも灰色**で、「閉じる」「結果をもう一度見る」がない。押すと新しいゲームが始まる(OPERATION.md に注意があったので押さなかった)。読み返す手段がないので、内容は押す前にスクロールして全部読み取る必要があった。
13. 起動直後の画面では、1ターン目の方針パネルを見てもスクロールしないと優先順位や主要行動が見えない。パネルは長く、必要な情報にたどり着くのにスクロールが必要(スクロール位置はタブを切り替えても保持される。便利だが、戻り忘れる)。
14. 地図の水路(青い線)をクリックしても何も起きない。区域のカードだけが選択対象。気づくまで一瞬迷った(軽微)。

## 5. 不具合に見える挙動

確実な不具合と言えるものは見つからなかった。気になった点:
- 結果カードが開いている間、背景のヘッダーの「残高」と季節表示がすでに次ターンの値に変わっている(例: 結果カードの期末残高 2,475 が背景で既に表示)。期待: カードを閉じるまでは前ターンの値か、または次ターンと分かる表示。軽微。
- 環境流水スライダーの値の読み取り: 1回目のクリックで 3,600、2回目で 2,650、第11ターンで 2,700 となった。クリック位置に応じた値で、意図どおり。表示の目盛り(最大値)は画面になく、最大値は分からない(感想)。
- 表の第1ターン「環境達成 100%」など、環境流水の達成度は常に 100%(目標が最低基準以上なら満たす定義に見えるが、これは推測)。

## 7. ほしい機能・改善案

優先度 高:
- 優先順位の影響の説明を、結果カードにも出す(例:「水が足りない場合、優先順位の低い○○から削られました」)。順位並べ替え画面にも「足りない時にどうなるか」を1行で。
- 今季取れる水量の見込み(予報降水から推定した利用可能量の範囲)を方針パネルに表示。
- 井戸ボタンが出ない区域では「井戸の建設には概査が必要」と表示する。
- 最終結果の推移表に、生活・産業の充足率の列を追加。

優先度 中:
- 概査と試掘・揚水試験の精度の違いを、ボタンの説明に書く(「推定幅 ±25%」「±8%」)。
- 「今季に自由に使える資金」から、選択中の主要行動の費用を引いた見込み残高を出す。
- 揚水上限スライダーを方針タブにも出す(区域タブへの導線だけでも)。
- 主要行動ボタンの選択中の文言が切れないようにする。
- 水収支の残差の指数表記を「0」または「ほぼ0」に。

優先度 低:
- 最終結果から結果を再表示できるようにする(または押す前に確認が出る)。
- 水路(青い線)をクリックしたときの反応。
- 単価・揚水費・維持費の目安の一覧。
