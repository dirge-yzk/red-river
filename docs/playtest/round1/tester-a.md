## 3. 最終結果
- ランク: **S** / 総合 **100%**
- 各指標 (すべて重み×1):
  - 農業用水の充足度 100% (供給 21,285 / 需要 21,300 WU)
  - 生活・産業用水の充足度 100% (供給 19,500 / 需要 19,500 WU)
  - 環境流水の達成度 100% (最低基準を満たしたのは 12/12 ターン)
  - 地下水の残存 100% (貯留量は開始時の 107%、揚水コスト上昇 0 区域)
  - 財政の健全性 100% (最終残高 7,065、基準 2,000、最低残高 800)
- 学習目標の振り返りの要点:
  1. 水収支: 12ターンの降水 311,090 WU は、蒸発散67%・用水供給13%・下流端流出15%・貯留増減6% に配分。収支の残差は最大 7.3E-012。
  2. 地下水のストック性: 貯留量は開始時の107%。涵養 22,201 WU に対し揚水 1,200 WU、河川へ 18,809 WU が湧出。
  3. 配分のトレードオフ: 農業100%・生活100%・環境12/12。最も満たせなかったのは農業用水。最終優先順位は 生活→環境→農業。
  4. 情報の価値: 調査3回・1,200。終了時の推定誤差は、調査した区域で平均3%、未調査の区域で平均12%。
  5. 不可逆性: どの区域も閾値を下回らず、揚水コストは上昇せず (揚水費の合計 146)。
- 費用と収入: 用水の収入 9,671 / 費用 6,406 (調査1,200・建設1,500・投資3,200・維持360・揚水146)。
- 推定と実際の地下水貯留量のグラフ: 中流農地は第1ターンに調査して終了時 +4%。市街地は第4ターンに初調査で +1%。上流・下流は未調査で +12% と -11%。

## 4. 詰まった点・分かりにくかった点
(以下は感想・意見を含む)
1. **主要行動ボタンの説明文の位置** (区域タブ): 「浸透改善: 地表流出を35%減らし…」「灌漑効率改善: 農業の正味需要が20%減ります」という説明が、対応するボタンの**上**にあるのか**下**にあるのか分かりにくい。最初は概査ボタンの下の説明を概査の説明だと思った。実際は次のボタンの説明で、概査と試掘・井戸建設には説明文がない。
2. **選択中のボタンの文字が切れる**: 「✓ 試掘・揚水試験を行う (費用 800) (クリックで取…」「✓ 灌漑効率を改善する (費用 2,000) (クリックで取…」のように、右端が切れる。取り消せることは分かるが、見切れている。
3. **ボタンの位置が状況で動く**: 農地タブは、井戸の有無や調査済みかどうかでボタンの縦位置が変わる。ターン3で、同じ場所を押すつもりが別の位置を押してしまった (何も選ばれなかった)。クリックのたびに撮影して確認して気づいた。
4. **「前季の利用可能量」が予測に使えない**: 方針タブの「前季の実績: 取水点の利用可能量 ○○ WU」を、今季使える水量の目安だと思って判断した。ターン5 (2,773) とターン10 (3,863) で不足を心配したが、実際はどちらも河川水で足りた。目安なのか、単に過去の値なのか、説明がほしい。
5. **残差が「5.5E-012」「-6.9E-012」のような指数表記**: 結果カードの「残差」。普通の人には何の数字か分からない (「収支は一致しています」と緑字で出ているので、問題ないことは分かる)。
6. **「－ 貯留の増加(土壌+地下水) -8,220」**: 項目名に「－」が付き、値もマイナスで、符号の意味が分かりにくい (二重否定のように読める)。学習目標1の注記が貯留の減少を説明していて、意味は推測できた。
7. **今季に自由に使える資金の表示**: 最終ターンの結果後、ヘッダーは残高 7,065 だが、パネルは 8,065 (7,065+翌年の交付金1,000?)。交付金は春に受け取るはずなので、冬の最終ターンの後に1,000が足されて見える理由は分からなかった。
8. **環境流水スライダーの最小値が季節で変わる**: 春2000、夏1800、秋・冬1500。説明に「最低基準」とは書かれているが、季節で変わる理由は書かれていない。
9. **最終結果の記述に違和感**: 「最も満たせなかったのは農業用水です」とあるが、農業の充足度は 100% (実際は 99.93%。ターン9は99%)。ほぼ満たしているので、「最も」の表現が大げさに見える。
10. **「河川」の「河」の文字だけ色が違って見える箇所**: 結果カードの「河川水 …」「(河川の目標 …)」の「河」(や「川」) だけ、色が違う文字として描画されている行がある (オレンジ・青っぽい)。意味のある強調かフォントの問題かは分からなかった。
11. **スライダー操作**: トラックのクリックで値が変わるのは分かりやすかった。ただ、クリックした位置の値が事前に分からず、環境流水の目標が 2,600 や 2,350 のような半端な値になった。
12. **季節が変わるとスライダーが初期値に戻る**: 環境流水の目標を2,600に上げても、次のターンに最低基準に戻る。毎回設定し直す必要があった。仕様か不具合かは分からない。
13. **方針タブのスクロール**: 方針タブは縦長で、財政・スライダー・優先順位・主要行動を見るのにスクロールが必要 (毎ターン `scroll` した)。スクロール位置は区域タブから戻ると維持される場合と、先頭に戻る場合があった。
14. **所要時間の目安**: 遊び方画面は「1プレイ 15〜25 分」と書いてあるが、実際は 5 分で終わった (ほとんどのターンが即決できたため)。

## 5. 不具合に見える挙動
- **操作 → 起きたこと → 期待したこと** の形式。
1. ターン3: 農地タブで (990,496) をクリック → 何も選択されなかった (画面上でボタンの位置が変わっていた) → 「井戸を建設する」が選ばれること。**ただし、これは私が位置を取り違えたもので、不具合ではない可能性が高い。** ボタンの位置が動くのは分かりにくい。
2. ターン10: 揚水上限を最大 (1,800) に上げた → 赤字の警告「推定の持続的揚水量を超えています (貯留量が減ります)」が出た。これは期待どおり。実際の揚水は 0 だったので、貯留への影響はなかった。
3. 結果カードの「残差」が 5.5E-012 などの指数表記になる。値が表示用に丸められていない。
4. 最終ターンの結果後に「今季に自由に使える資金」が 8,065 と表示される (ヘッダーは 7,065)。上記4章の7番と同じ。
- それ以外で、画面の表示と操作が食い違った箇所は見つからなかった。クリックの結果はおおむね想定どおり。

## 6. 難易度の感想
**2 / 5 (やや易しい)**

根拠:
- 12ターンすべてで、農業・生活産業・環境流水の3つとも最低基準を満たせた (ランクS・総合100%)。不足が出たのはターン9 (少雨の春) の農業 99% だけで、それも井戸で補えた。
- 序盤に調べて井戸を作った地下水の貯留 (約1.5万WU) が大きく、渇水の気配のあるターン (乾燥した冬、少雨の春) でも困らなかった。
- 残高は 800 → 7,065 と一方的に増え、使い切れなかった。ターン後半は何を買っても余るので、お金のトレードオフがあまり感じられない。
- 判断に必要な情報はおおむね足りていた。ただ、「前季の利用可能量」が今季の予測に使えるのか分からず、不安から不要な対策 (揚水上限を最大に) をした。
- 選べる行動は、調査・井戸・浸透改善・灌漑改善だけで少ない (農地は4種類、市街地は3種類)。上流と下流の区域でできる行動は確認していない (クリックしていない)。
- なお、シナリオ「平年」で「地下水の情報は未知」とあるが、実際は普通にやるだけでほぼ満点になった。「渇水」シナリオなら難しいのかもしれないが、未確認。

## 7. ほしい機能・改善案
(優先度: 高/中/低)
- **高**: 今季の予報から「今季使えそうな河川水の量」の目安を出す。前季の利用可能量だけでは、不足するか判断できなかった。
- **高**: 主要行動ボタンの説明を、ボタンのすぐ下に揃える (または各ボタンにも説明文を付ける)。概査・試掘・井戸建設にも説明がほしい。
- **中**: 結果カードで、前季と比べた変化 (土壌水分・地下水の増減) を矢印などで見られるようにする。
- **中**: 環境流水の目標を、季節が変わっても前の値のまま引き継ぐ (または「前季と同じ」ボタン)。
- **中**: 方針タブで、設定した値の「合計」(農+生+環) と、前季の利用可能量との差を並べて見せる。足りるかどうかが一目で分かる。
- **中**: お金が余りすぎるので、余剰資金の使い道 (例えば基金、寄付、追加の施設) があるとよい。または財政の評価の基準を厳しくする。
- **低**: 結果カードの残差を、指数表記ではなく「0」や「誤差なし」と表示する。
- **低**: 選択中ボタンの「(クリックで取消)」を短くする (文字が切れる)。
- **低**: 方針タブの上部に、残高・今季の資金を固定表示する (スクロールしても見える)。

## 8. もう一度遊ぶなら
- やり方を変える。今回は調査・井戸・灌漑改善を序盤に済ませ、その後は余力があった。次回は次のことを試したい。
  - 調査を一切せずに進めて、情報の価値 (学習目標4) の差を体感する。
  - 井戸を作らない、または揚水上限を最大にして使い続けて、地下水の閾値 (貯留 4,000 WU) を割る場面を見る (学習目標5の不可逆性が実際に起きるか確認したい)。
  - 優先順位を「環境」を最優先に変えて、農業が不足する場面を作る。
  - 「渇水」シナリオで同じ方針が通用するか確かめる。
- 理由: 今回は何も失敗しなかったので、このゲームが伝えたい「トレードオフ」「不可逆性」を体感できていない。
