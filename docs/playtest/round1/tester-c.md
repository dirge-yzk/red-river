## 3. 最終結果
- ランク B / 総合 67%(プレイ時間 6.6分(目標15〜25分)、方針決定は平均23秒(目標45〜90秒))
- 指標(評価 / 重み): 農業用水の充足度 66%(供給18,613/需要28,080)×2、生活・産業用水 100% ×1、環境流水の達成度 90%(最低基準を満たしたのは10/12ターン)×2、地下水の残存 42%(貯留は開始時の37%、揚水コスト上昇1区域)×1、財政の健全性 100%(最終残高6,832、最低残高389)×1
- 注記: 「総合は重み付き平均だが、最も低い指標+25%を超えない」。農業66%に引っ張られて総合が上がらない設計。
- 学習目標の要点: (1)水収支: 降水208,815WUは蒸発散78%、用水18%、流出12%、貯留-9%。(2)地下水: 涵養0に対し揚水6,060を汲み、貯留は開始時の37%に。(3)トレードオフ: 農66%、生100%、環境は10/12ターン達成。(4)情報: 調査3回・1,200、調査区域の推定誤差は平均7%、未調査は43%。(5)不可逆性: 農地が閾値割れし揚水コストが恒久上昇(揚水費合計1,176)。
- 費用と収入: 用水の収入9,309、費用6,276。

## 4. 詰まった点・分かりにくかった点
- 序盤の優先順位: 優先順位(生活→農業→環境)が初期状態で環境が最後であることと、春にしか変えられないことに、1年目夏まで気づかなかった。1年目春は初期値のまま進めて環境14%になった。春のターン開始時に、並べ替えの重要性を示す注意があるとよい。
- 「利用可能量」の意味: 取水点のラベル「前季の利用可能量」が、結果カードの「河川水の供給合計」と合わないことがあった(例: 2年夏の結果、農4300+生2200=6500、下流1269で合計7769のはずだが、ラベルは7,202と表示)。何を指す数字か分からず、次季の予測にどう使うか迷った。
- 降水予報と川の水量の対応: 降水量が多い予報(220〜320mm)でも、土壌と蒸発散に吸われて川は思ったほど増えなかった(2年夏)。予報の降水量から川の量を推定する手がかりが画面になく、読み違えた。
- 揚水上限スライダーは毎ターン初期値(約700〜750)に戻る。農業の川目標は毎ターン最大に戻る。前季の設定が引き継がれないので毎回設定し直しになる(仕様か不明)。
- 揚水上限を大きくすると「推定の持続可能量を超えています」の警告だけで、閾値(4000)を割る見込みかは出ない。計算すれば分かるが、私は計算を怠って3年春に閾値を割った。
- 結果カードを見ている間、ヘッダーはすでに次のターンの表示になっている(例: 秋の結果を見ている間「冬 ターン12/12」)。仕様と思われるが、最初は結果がどのターンのものか一瞬迷った。
- スライダーのクリック位置が、スクロール状態によってずれる(揚水上限スライダーはパネルのスクロール位置で縦位置が変わる)ので、毎回スクリーンショットで確認する必要があった。
- 市街地の「井戸なし」表示でも「地下水100WU」を供給している(2年冬の結果)。井戸なしで地下水が使える理由が分からない。

## 5. 不具合に見える挙動
- 上の「井戸なしなのに地下水100供給」: 市街地に井戸を建てていないのに、生活・産業用水の供給に「地下水100WU」と表示された(2年冬)。期待: 井戸なしなら地下水は0。農地の「持続的揚水量」と別に、市街地側の未建設の井戸から汲める仕様があるのか不明。
- 他に、操作と結果が食い違った箇所はなかった(誤クリックなし)。

## 6. 難易度の感想
- 評価: 3(ちょうど良い)〜やや易しい寄り。
- 根拠: 初見でも、3ターン目までに環境流水を守る配分は見つけられた。ただし、初見で気づきにくい罠(優先順位が春にしか変えられない、川の量を予報から読めない、地下水の閾値)があり、B評価の原因になった。農業66%が足を引っ張った。農業を100%に近づけるには井戸の追加や浸透改善が必要だが、検証できなかった。
- 選べる行動の数: 1ターン1行動で、選択肢は少ない(調査、井戸、浸透改善、灌漑効率)。判断は主に川目標、揚水上限、優先順位の3つ。人によっては選択肢が少ないと感じるかもしれない。
- 判断に必要な情報: 足りない。次の項目に書いた。

### 判断の根拠にした情報
- 前季の取水点の利用可能量と下流端の流量(最重要)。それでも、降水量との関係は読めなかった。
- 降水予報の幅と気象カード名(少雨・渇水・乾燥・平年)。
- 残高(調査と投資の可否)、結果カードの充足率と環境達成度、学習目標の一言(次の行動のヒントになった)。
- 地下水の推定値と幅、持続的揚水量の推定。

### 足りないと感じた情報
- 川の水量の見通し(予報降水量から、取水点で使える水がどのくらいになりそうかの目安)。これが一番ほしかった。
- 地下水が閾値(4000など)を割る見込みの事前警告(スライダーを動かしたときに「このままだと今季末に閾値割れ」と出る)。
- 優先順位が春にしか変えられないことの強調。
- 前季の設定(川目標、揚水上限)の引き継ぎ。
- 浸透改善の効果の大きさ(何WU増えるか)。効果が不明で、一度も試さなかった。
- 収入と費用の見通し(次季の見込み)。

## 7. ほしい機能・改善案
1. (高)予報降水量から取水点の利用可能量の目安を出す表示、または過去の「降水量→利用可能量」の履歴表。
2. (高)地下水の閾値割れ予測の警告(揚水上限スライダーの横に「今季末の推定貯留量」を表示)。
3. (中)春のターン開始時の優先順位に関するヒント、または並べ替えのできない季節の注記を目立たせる。
4. (中)前季の川目標・揚水上限を引き継ぐ初期値。
5. (中)結果カードで、農業の不足分が「川の制約」か「井戸の制約」かを示す(学習目標3が一部出していたが、毎回は出ない)。
6. (低)市街地に井戸がないのに地下水が使えた理由の説明。
7. (低)施策ごとの効果見込み(浸透改善は何WU増えるのか)。

## 8. もう一度遊ぶなら
- やり方を変える。理由: 総合は農業の充足率(66%)が足を引っ張った。
  - 1年春から優先順位を「生活→環境→農業」にし、環境を確実に守る。農業は井戸で補う。
  - 1年春は概査ではなく、先に井戸の建設に向けて動く(概査は春、井戸は夏、のように前倒し)。農業が不足する1年夏・2年夏が最大の損失だった。
  - 地下水は閾値(農地4000)を割らない範囲で揚水量を決める(割ると揚水コストが上がる)。3年春の揚水上限1800は避ける。
  - 「降水が多い予報でも川は増えない」ことを前提に、川目標を保守的に設定する。
  - 残高は終盤に6,800も残ったので、浸透改善や灌漑・井戸など、使い道の効果を試して農業充足率を上げる。
