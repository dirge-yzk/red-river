# プレイテスト 1回目のまとめと対応

## テストの方法

「ゲームの操作方法しか知らない AI」に遊ばせました。内部資料・ソースコード・数値は渡さず、操作説明書(`OPERATION-round1.md`)と、画面操作のヘルパーだけを与え、スクリーンショットとクリックで最後まで遊ばせています。3人が別の遊び方で、並列に遊びました。報告書は `round1/` にあります。

| テスター | シナリオ | 遊び方 | ランク | 難易度の感想 |
|---|---|---|---|---|
| tester-a | 平年 (シード101) | 初めてのプレイヤーとして自然に | S (100%) | 2/5 (易しい) |
| tester-b | 平年 (シード202) | 全機能を試す | A (84%) | 2/5 (易しい) |
| tester-c | 渇水 (シード303) | 高ランクを狙う | B (67%) | 3/5 (ちょうど良い〜易しい寄り) |

## 見つかったこと

### 難易度
- 平年は、何もしなくてもほぼ満点になる (残高も 800 → 7,000 以上と一方的に増え、トレードオフを体感できない)。
- 簡易プレイヤーでの測定でも、「何もしない」がほぼ全シナリオで最高点に近かった。生活・産業用水と財政の評価は、常に満点だった。

### 不足していた機能・情報 (3人中2人以上が指摘したものを優先)
1. **今季の見込み** (3人とも優先度「高」): 「前季の利用可能量」は今季の予測に使えず、需要の合計が足りるかを判断できない。
2. **揚水の事前警告** (C: 高): 揚水上限を最大にして、閾値を割って初めて気づいた。
3. **優先順位の説明**: 水が足りないときの動き (下の項目から削られる) が、最終結果まで分からない。春にしか変えられないことに気づくのが遅れた。
4. **設定の引き継ぎ** (A・C): 環境流水・揚水上限・取水目標が、毎ターン初期値に戻る。
5. **主要行動ボタン** (A・B・C): 説明がどのボタンのものか不明。選択中の文言が切れる。状況でボタンの位置が動く。井戸の建設に概査が必要なことが分からない。
6. **結果カードの数字がつながらない** (A・C): 「利用可能量」と取水・下流流量の関係が不明。残差が指数表記。水収支の「−」と負の値が二重否定に読める。市街地に井戸がないのに地下水が供給される理由が説明されない。
7. **表示の不整合**: 結果を見ている間、ヘッダーが次のターンの表示 (3人とも)。最終ターン後に「自由に使える資金」へ翌年の交付金が足されて表示される (A)。
8. **最終結果**: 推移表に生活・産業の列がない (B)。読み返せない (B)。「最も満たせなかった」が、99%でも出る (A)。
9. **費用の見積もり** (B・C): 収入の単価・揚水費・維持費、選択中の行動の費用を引いた見込み残高、浸透改善の効果の大きさ。

## 対応 (実装したもの)

| 指摘 | 対応 |
|---|---|
| 1 | `Forecast` を追加。予報の降水範囲(下限・中央・上限)と、見えている土壌水分・推定の地下水だけから、取水点の利用可能量と下流流量を計算して、方針パネルに表示する。目標の合計、環境流水の最低基準との比較、「降水が少ない側では不足する」警告も出す。隠しの真の地下水や、確定済みの気象は使わない (テストで確認)。 |
| 2 | 揚水スライダーを「今季の方針」タブへ移し、上限まで汲んだ場合の今季末の推定貯留量と閾値を並べて表示。閾値を割りそうなら警告する。 |
| 3 | 優先順位の見出しに「水が足りないときは、下の項目から削られる」を明記。春は「★ 春です。1年に1回だけ並べ替えられます」を強調。結果カードの解説に、不足した用途のうち優先順位が最も低いものを名指しする。 |
| 4 | 農業・生活産業は「需要の何割か」、環境流水は「最低基準への上乗せ」、揚水上限は前の値を、次の季節の初期値に引き継ぐ。 |
| 5 | 全区域で同じ並びに固定 (概査 / 試掘 / 井戸 / 浸透改善 / 灌漑)。できない行動は理由を書いて押せなくし (「先に概査が必要」「資金不足」)、済んだ行動は「実施済み」と出す。各ボタンの下に、効果と精度 (±25% / ±8%)、浸透改善の効果量の目安 (年あたり WU) を書く。選択中の文言を短縮。 |
| 6 | 結果カードを「河川水の流れ」(利用可能量 − 取水 + 湿地の流入 = 下流流量) と「降水の行き先」(合計が降水に一致) の、つながる表に変更。残差は「差 0」と表示。地下水は全区域の井戸の合計である旨を追記。 |
| 7 | 結果表示中のヘッダーは、その結果のターンの表示にする。最終ターン後は交付金を足さない。 |
| 8 | 推移表に生活・産業の列を追加。「閉じて地図を見る」と、右下のボタンからの開き直しを追加。99%以上なら「どの用途もほぼ満たせました」。 |
| 9 | 方針パネルの財政に、収入の単価・費用の一覧と、選択中の行動の費用を引いた見込みの資金を表示。 |
| 難易度 | 標準シナリオの需要を増やし(農業 ×1.4、生活・産業 ×1.2、環境基準 ×1.2)、降水を −10%、地下水の初期量を −20%、収入を −20%、財政の基準額を引き上げ。配分優先順位の初期値を「農業 → 環境流水 → 生活・産業」に変更し、何も考えずに進めると生活・産業が最初に不足するようにした。地下水の評価の基準比は、自然な減少の水準(0.70)に合わせた。 |

調整後の簡易プレイヤー(20シード平均)では、標準シナリオで「何もしない」0.76、賢い戦略の最良 0.87、地下水の使い切り 0.59 となった。
