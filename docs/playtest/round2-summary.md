## 最重要の不具合: 長期の試練で画面が固まる

テスターが「1ターン目でスライダーを触ると画面が固まる」と報告しました。メッセージを記録 (`WATERGAME_TRACE=1`) すると、5秒間に 3,253 件の入力が飛んでいました。

- 原因: Avalonia.FuncUI は、同じ位置の子要素を使い回します。方針パネルは「条件によって行が増減する」ので、行の増減で位置がずれ、農業・生活産業・環境流水・揚水上限のスライダーのコントロールが別の役割に使い回されました。値の更新が別のスライダーの変更通知になり、互いに書き換え合って止まらなくなっていました。
- 対応: すべてのスライダーに固有のキー (`View.withKey`) を付け、タブの中身もターンごとにキーを替えるようにした。修正後は同じ操作で 3 件。
- 再発防止: `tools/ui-smoke.sh` を追加。6シナリオを実画面 (Xvfb) で数ターン進め、1ターンあたり 12 件を超える入力が出たら失敗にする。

## 見つかった改善点と対応

| 指摘 | 対応 |
|---|---|
| スライダーを右端にしても、需要ぴったりにならない (50刻みで丸め) | 右端から半刻み以内は需要そのものに丸める。環境流水は最低基準から刻む |
| 井戸がない区域でも、自然な減少だけで「揚水コスト上昇」が立つ (市街地拡大で地下水が8%・総合が頭打ち) | 井戸のある区域だけフラグを立てる |
| 推定が「±50%」と書かれるだけで、実際の範囲がつかめない / 「乏しい」の基準が不明 | 推定の実際の範囲 (WU) を数値で表示。有望 (800以上)・中程度 (350以上)・乏しい の基準を併記。推定の下限が「乏しい」になる場合は、調査を勧める |
| 井戸は「次の季節から使える」ことを見落とす | 橙色の太字で強調 (行動の説明・区域タブの下・ヒント) |
| 環境流水を守る方法が分からない | 見込みが△/⚠のとき、「農業・生活産業の目標を下げ、不足分を井戸で補う」(井戸がなければ「井戸の建設が必要」) を表示 |
| 評価の重みや「最低指標+25%」の仕組みが最後まで分からない | 最初のターンの方針パネルに重みと上限規則を表示。最終結果に地下水の基準 (開始時の何%以上で満点) を表示 |
| 優先順位の意味 (環境流水は取水後に下流に残る水) が分かりにくい / 春にしか変えられない | 説明を追加。「1位へ」ボタンを追加。初期の順位で生活・産業が最下位のときは確認を促す |
| 前季の設定が引き継がれることが分からない | スライダーの横に「需要の○%」を表示 |
| 最終結果の読み方 (推定のグラフ、縦軸、時間) | グラフの説明を追記。時間表示は「目安」に |
| チュートリアルが易しすぎる (井戸を使わずに満点) | 作り直し (下記) |
| 渇水が厳しすぎる (C 55%) | 農業需要を平年と同じに、少雨カードの重みを下げて緩和 |
| 市街地拡大の需要増・舗装の意味が分からない | 方針パネルに、年あたりの増加率、舗装の意味、来年の同じ季節の需要を表示 |
| 用語 (流出係数・土壌保水容量)、降水の行き先の「貯留の増減」の符号が分かりにくい | 区域タブと結果カードに説明を追加 |
| 結果カードを開いたとき、前のスクロール位置のまま | カードごとにキーを替えて、先頭から表示 |
| ヒントが「今季の方針」タブにしかなく、区域タブでは見えない | ヒントを右パネルの上に固定 |

### チュートリアルの作り直し

- 気象カードを固定 (春は平年、夏は渇水、秋は少雨、冬は平年)。
- 需要を上げ、初期設定のままだと夏〜秋に生活・産業用水や環境流水が不足するようにした。
- ヒントの流れ: 春 = 見込みの読み方、優先順位 (春だけ)、概査 → 夏 = 井戸の建設 (費用 1,500、次の季節から使える) → 秋 = 揚水上限 → 冬 = 振り返り。
- 簡易プレイヤーでの確認 (10シード平均): 何もしない場合 B (約 70〜76%)、ヒントどおり遊ぶと A〜S (約 89%)。テストで固定。

## 簡易プレイヤーによる難易度の測定 (20シード、総合点の平均)

| シナリオ | 何もしない | 賢い方針 (春に生活産業の順位を上げ、農地の概査 → 井戸) |
|---|---|---|
| チュートリアル | 0.76 | 0.89 |
| 平年 | 0.76 | 0.85 |
| 渇水 | 0.60 | 0.67 |
| 市街地拡大 | 0.79 | 0.83 |
| 乾燥地 | 0.59 | 0.68 |
| 長期の試練 | 0.53 | 0.55 |

簡易プレイヤーは粗いので、人間のように環境流水と揚水を調整できません。実際の難易度は、AI テスターのプレイで確認しています (3回目)。

## まだ対応していないこと

- 遊んでいる最中に、現在の指標 (地下水の残り具合など) を見る表示。
- 長期の試練で、先の年の見通しを示す情報。
- 人間による試遊 (AI テスターだけで、人間の遊び手はまだ確認していません)。
