# プレイテスト 3回目のまとめと対応

## テストの方法

2回目の改善を入れたビルドで、AI テスター3人が別々のシナリオを遊びました (操作説明書だけを渡し、内部資料は読ませていません)。報告書は `round3/` にあります。

| テスター | シナリオ | 結果 | 難易度の感想 |
|---|---|---|---|
| r3-tutorial | チュートリアル (4ターン) | S (93%)、約2分 | 2/5 (ヒントどおりに進めれば易しい) |
| r3-long | 長期の試練 (20ターン) | C (25%) | 4/5 |
| r3-urban | 市街地拡大 (12ターン) | C (62%) | 4/5 |

## 確認できたこと

- **長期の試練で画面が固まる不具合は再現しませんでした。** 20ターン通して、スライダーを40回以上操作し、優先順位ボタン・タブの切り替え・スクロールも試しています (ドラッグ操作は試していません)。
- チュートリアルは、ヒントに従えば S、従わずに何もしないと B 程度になるように調整できています。井戸が効いたこと (秋の農業 44% → 83%) と、概査で推定の幅が狭まることは、テスターに伝わりました。
- 長期の試練の C は、序盤に持続量を超えて揚水を続けた結果で、最終的に地下水が開始時の 13%、資金も尽きました。「高難度」としての手応えはあります。簡易プレイヤー (粗い方針) の平均は B〜C です。

## 見つかった問題と対応

| 指摘 | 対応 |
|---|---|
| 最終結果の振り返りに「846096657842263552%」のような桁外れの誤差が出る (実際の貯留量がほぼ0のとき、割合の分母が0に近くなる) | 実際の貯留量が 100 WU 未満のときは割合を出さず、「ほぼ空でした (推定との差 ○ WU)」と表示。テストを追加 (修正前のコードでは失敗することを確認) |
| 季節が変わると、スライダーの横に「需要の 267%」などと出る (結果カードの背後の方針パネルが、前の季節の目標のまま次の季節の需要と比べていた) | 季節を進めた時点で、次の季節の初期値にそろえる。表示の割合は 100% で頭打ち。テストを追加 |
| 揚水上限を 0 にしても、次の季節に初期値へ戻る | 0 も含めて前の値を引き継ぐ。完成直後の井戸だけ初期値から始める。テストを追加 |
| 環境流水の目標に、前季の上乗せが残っていて気づかない | 「最低基準 ○ + 上乗せ ○」と内訳を表示 |
| 「推定が閾値より上なのに揚水コスト上昇」(判定は実際の貯留量) | 説明を追加 |
| 市街地拡大: 地下水の評価がプレイ中にまったく見えず、最終画面で 37% と知って総合が頭打ちに | 方針パネルに「地下水の評価の目安」(推定の貯留量が開始時の何%か、基準、コスト上昇の区域数。基準を下回れば警告) を追加 |
| 市街地拡大: 流出係数が増えるはずなのに、表示は 0.55 のまま | 区域タブに、舗装・浸透改善を反映した今の値 (開始時の値つき) を表示 |
| 優先順位の警告が読み間違えやすい / 環境流水が最下位の副作用が出ない | 最下位の用途ごとに文面を出し分け (環境流水が最下位なら、最低基準を割りやすくなると説明) |
| チュートリアルの説明が「夏の渇水を井戸で乗り切る」だが、井戸は秋から | 「夏は優先順位で、秋からは井戸で補う」に修正 |

## 残っている課題

- 長期の試練は、判断が濃いのが前半 (最初の8ターンほど) で、中盤は設定の繰り返しに感じられる (テスターの感想)。20ターンという長さはご要望どおりですが、中盤に出来事を足す余地があります。
- 優先順位の説明 (環境流水が「用途」として並ぶ理由) は、チュートリアルでも1回では理解しにくいという感想でした。
- 3回目の後に入れた修正 (上記の表) のうち、画面の確認は煙テスト (固まりがないことの確認) とユニットテストまでで、AI テスターによる再プレイはしていません。
- 人間のプレイテストは未実施です。
