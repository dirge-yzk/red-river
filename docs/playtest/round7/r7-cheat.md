## 1. 条件

- シナリオ: 渇水【特殊】 / シード: 502 / `--skip-intro` で起動 / DN=272
- プレイ範囲: 12ターン全部(最終報告書の1ページ目と2ページ目まで読めた。3・4ページ目は後述の不具合で開けなかった)
- 方針: 序盤は環境流水を最優先にして、農業の取水を約33%(ダイヤルを左上あたり)に絞り、指令を意図的に未達にした。1回目の冬(第4季)は「前向きに報告」、2回目の冬(第8季)は「重大な問題を隠す」、3回目の冬(第12季)も「重大な問題を隠す」を選んだ。設備(調査・井戸など)は一切使っていない。

## 3. 最終結果

- 費用の合計 0(設備を一切使わなかった)、用水の収入 2,700

  - 第1号 農業85% → 実績33% 未達 / 報告「一部達成(虚偽)」 / 信頼-10
  - 第2号 生活90% → 52% 未達 / 「報告せず(虚偽)」 / -10

## 4. 詰まった点・分かりにくかった点

- **最終報告書2ページ目で「前へ・次へ・閉じて地図を見る」の押しボタンが見えず、ページ送りができなくなった。** 1ページ目では下に前へ/次へとナイフスイッチがあったが、2ページ目は学習目標5つのボックスが下まで伸び、その位置に「同じシードで再挑戦」「新しいシード」「シナリオ選択へ」の3つしかなく、ページ送りの釦が出ていない。1ページ目の釦の位置(533,706)や(400,706)、下端(533,782)をクリックしても反応なし。マウスホイールのスクロールも効かなかった。結果として3・4ページ目は読めなかった。ここで再挑戦ボタンを押すと新しいゲームが始まってしまうため、押さずに終わった。
- 年次報告の「実際の判定」が、第2号・第3号のような期限が今季の指令では「今季の結果で判定」「判定のあとに報告」と出る。冬の運転日報で初めて確定する。期限が冬(または冬のひとつ前)の指令は、その冬のうちに報告する対象になる(第3号と第5号は期限が冬だったので、判定前に報告方針を選ぶことになった)。つまり「判定前に方針を決める」ことになるのが少し分かりにくかった。
- 日報ハイライトの文言「(実際 未達 → 報告 報告しない)」は、「報告 報告しない」と「報告」が重なって読みにくい(「報告 報告しない」は折り返し位置で「報告 報告し/ない」と割れて見えた箇所もあった)。
- 日報に「整合性リスクが 60 に達しました」と出た時、ヘッダーのメーターは96だった。「60に達した」と「96」の食い違いが、最初は意味が分からなかった(60が閾値で、96は実際の値と推測したが、画面からは確かめられていない)。
- 農業を休止した冬でも、日報の農業用水充足率が100%と出る(需要0のため)。指令の期間充足率には影響しないように見えたが、100%と出ると一瞬ごまかされた気分になる。

## 5. 不具合に見える挙動

- 最終報告書2ページ目のページ送り釦の消失(上記)。操作: 2ページ目で次へ/前へ/閉じて地図を見るを押そうとした → 釦が画面にない / 反応なし → 3・4ページ目へ進める、または閉じられるのを期待した。
- 監査後の監査リスクが0ではなく30になった。マニュアルを読んでいないので、仕様かどうかは分からなかった(画面には理由の説明がない)。
- 優先順位の変更を春に行った後、冬の日報で農業需要が0(休止)になるが、このとき環境流水・生活が優先でも水不足の見込みは出る(河川水の不足: 生活・産業 887WU)。これは不具合ではなく仕様の可能性が高い。
- 上記以外に、クリックの空振りはなかった。

## 6. 難易度の感想

- 3 / 5(ただし私は水を大きく絞る遊び方なので、一般の難易度としては参考程度)
- 根拠: 渇水で河川水が少なく、環境流水を満たすと生活・産業まで足りなくなる(T3、T4、T5で生活 67%、66%、40%)。ただし、環境流水を最優先にして設備を使わなくても、地下水・財政は100%、環境100%で、ランクCまで行った。難しさの大半は、指令(農業85〜100%)と環境流水の両立。設備を使わなかったので、選べる行動の数が足りているかは判断できない。
- 判断に必要な情報は、監査まわりについては足りていた(リスクのメーター、予兆灯、記録欄)。ただし、リスクが毎季節+3ずつ上がる仕組みは、画面上のどこにも書かれていない(OPERATION.mdには「毎季節上がり続けます」とあった)。

## 8. もう一度遊ぶなら

- 虚偽の報告を「前向き」だけにして、リスクが60に届かないよう調整して、リスクの増え方と信頼の増減を比べたい。今回は「隠す」でリスクが一気に96まで跳ねたので、「前向き」だと、どの冬でどこまで安全かを確かめたい。
- 正直な報告のプレイと、シードを揃えて比べたい。今回は「同じ条件で正直に報告した場合」を遊べていないので、虚偽が得か損かは、画面上の数字からの推定にとどまる。

## 10. 遊びごたえ

- 虚偽の仕組みについては、工夫した分(隠す・前向き・正確を使い分ける)だけ、リスクと信頼の動きが変わり、観察しがいがあった。
- 水の管理そのものは、設備を使わず、取水の絞りだけで進めたので、工夫の差は測れなかった。最初の設定のまま(農業・生活とも需要どおり)なら、指令達成度は変わったはずだが、試していないので分からない。

### (a) 虚偽の報告の直後に、リスク・信頼・補助金はどう変わったか。予想どおりか

- 第4季(前向きに報告): リスク 0 → 18。日報には「+15」とあったので、+3の差は、同じ季節に「露見していない虚偽が1件ある」分の季節加算だと推測した(第5季以降は毎季節+3だったので辻褄は合うが、画面にそう書いてあったわけではない)。信頼は 40 → 50 で、+10。第1号の未達ペナルティ(-10)が打ち消された形(私の解釈)。
- 第8季(隠す、2件): リスク 27 → 96。「+60」(1件+30 × 2件)と、虚偽が3件残っている分(3×3=9)が加わって27+60+9=96(私の計算。9の内訳は画面には出ていない)。信頼は 40 → 50(第3号の-10が日報で出て、第2号・第3号の隠しで+10ずつ戻った、と解釈すると辻褄が合う)。
- 補助金: 「虚偽の報告で補助金が増えた」という表示は、日報や指令ページには一度も出なかった。資金の増減は季節ごとの収入と交付金が混ざっており、虚偽による補助金の増加分は、画面からは分離できなかった。→ **補助金がどう変わったかは分からなかった。**
- 予想どおりか: マニュアル(OPERATION.md)にあった「信頼や補助金が増える」「リスクが上がる」は、信頼については予想どおり。補助金は確認できなかった。+30/+15の大きさと、毎季節+3の加算は、事前には知らなかった。

### (b) 予兆から監査までの流れは、事前に分かったか

- 分かった。リスクが60を超えた季節(第8季冬)の日報に「監査の予兆: 次の季節に監査が入ります」と「整合性リスクが60に達しました。次の季節に監査が入ります」が出て、次の季節(第9季春)の運転・指令ページの左下に赤い表示灯「監査の予兆: …今季の終わりに監査が入ります」が出て、その季節の終わりに監査が入った。予告は、実際の監査より1季節前に出る。
- ただし、予兆を見てからできることは少ない。虚偽を取り消す手段は画面になく(春に正確に報告しても過去の虚偽は残る)、監査は避けられなかった(私は避けようとしなかったので、避けられるかは試していない)。
- リスクが60に届く前に、「このまま行くと60になる」という予告は出ない。リスクの針と数字を見て、自分で計算するしかない。メーターに60の目印があるかは、画面の見た目(針の位置)からは確かめられなかった。
