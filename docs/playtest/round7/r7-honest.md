## 4. 詰まった点・分かりにくかった点

依頼された (a)〜(f) に分けて書く。

### (a) 年次報告の意味・選択肢・結果が、指令ページだけで分かったか

- **指令ページだけでは、分からなかった(と感じた)。** ただし私は先にマニュアルを読んでいたので、「読まずに遊んだ場合」は予想になる。
- 指令ページのパネルの見出しは「年次報告 (冬の季節に、その年に期限が来た指令の結果を、中央へ報告します)」。これで分かるのは「冬に、期限が来た指令の結果を報告する」ことまで。
- 3つのボタン「正確に報告」「前向きに報告」「重大な問題を隠す」には、**それぞれを選ぶと何が起きるかの説明がない**。指令ページに「監査リスク」の語もなかった。ボタンの言葉から想像はつくが、リスクが上がること、監査が入ること、罰則があることは、指令ページ上には書かれていなかった(分からなかった)。
- 選択肢の効果(前向き=判定を一段よく見せる・リスク+15、隠す=未達を報告から外す・リスク+30、正確=リスク-10)は、マニュアル2ページ目の「年次報告」の項に書いてあった。監査の規則(60で予兆、次の季節の終わりに監査、罰則の中身)は、マニュアル3ページ目の「整合性リスクと監査」の項。つまり、**指令ページ → マニュアルの2〜3ページ目と、画面をまたいで読まないと全体が分からない**。
- 冬の運転ページ・設備ページの下の表示灯に「年次報告の季節です。指令ページで報告方針を選んでください (今の選択: 正確に報告)」と出る。これは、冬に指令ページへ行く手がかりとして役に立った。
- 結果は、冬の日報のハイライトに「年次報告 (正確に報告): 実際の結果を、そのまま報告しました。整合性リスク -10。」と1行で出る。分かりやすい一方で、リスクがもともと0のときに「-10」と書かれると、メーターは動かない(0のまま)ので、「-10 は何から何になったのか」が画面からは分からなかった(0で止まる=下限0だろうと思ったが、画面にそう書いてはない。推測)。
- 第1年の冬(第4季)に初めて年次報告のパネルを見たとき、表は「第1号 / 達成 / 達成」だけだった。冬の前(春・夏・秋)は「報告する指令は、まだありません」と出て、ボタンは暗く「報告は、冬の季節に提出します (今は選べません)」。この「選べない」の説明は親切だった。

### (b) 「実際の判定」と「報告する判定」の表示は分かりやすかったか

- 表(指令 / 実際の判定 / 報告する判定)の並びは分かりやすかった。「正確に報告」のとき、2列が同じ言葉(達成/達成)になるので、「正確」の意味が目で確かめられた。
- ただし、まだ判定されていない指令の行は、判定の前は「実際の判定: 今季の結果で判定 / 報告する判定: 判定のあとに報告」と出る。第8季・第12季(期限が冬)は、運転を開始して判定が出る前の画面なので、この文言になる。「判定のあとに報告」は、**今選んだ方針が、この判定にも適用されるのか**が一目では分からなかった(日報では、同じ冬に判定された指令も「正確に報告」で報告されていたので、適用された。これは日報を見て分かったこと)。
- 「前向きに報告」「隠す」を選ぶと「報告する判定」の列がどう変わって見えるのかは、**試していないので分からない**。選んだ直後の表の変わり方がプレビューとして出るのかも不明。
- 右の列の「報告と監査の記録」は、「第4季 正確に報告」のように**季節番号だけ**で、どの指令についての報告かは出ない。年の数え方(「第4季」=1年目の冬)も、季節の表示(「1年目 冬」)と書き方が違うので、一瞬迷った。

### (c) 監査リスクのメーターの意味は分かったか

- ヘッダーの「監査リスク」は、針式のメーターと3桁の数字(0〜100と、OPERATION.mdにあった)。**私のプレイでは常に 0**。針は文字盤の左下を向き、盤の上のほうに、白い短い印が出ていた。この白い印が何かは、画面にもマニュアルにも説明がなかった(60のしきい値の印だろうと思ったが、確かめていない。**分からなかった**)。
- 数字が0〜100であること、60で監査の予兆が出ることは、マニュアル3ページ目の文章から分かる。メーター自体には、60の目盛りの数字や「警戒」の色分けの凡例はなかった(色の帯は赤と緑のように見えたが、意味の説明は見つけられなかった)。
- リスクが上がるところは見ていない(虚偽の報告をしていないので)ため、メーターの動きは**分からなかった**。「監査の予兆」(地図の下の赤い表示灯)も、一度も点灯しなかったので、見ていない。

- **2**(やや易しい)。理由: 平年・シード501は、第1年の春・夏を除いて水が足りており、農業100%を維持しながら、揚水0で最後まで進められた(揚水0・閾値割れ0)。指令5件はすべて達成できた。失敗したのは、第1・2季の生活産業(0%・13%)と、環境流水(40%台が3ターン)。

## 7. ほしい機能・改善案(優先度つき)

- 【高】指令ページの年次報告パネルに、3つの方針の1行説明(例: 「前向き: 判定を一段よく見せる。リスク+15」)を、ボタンの下か横に出す。今は、指令ページだけでは効果と代償が分からない。
- 【高】方針を押した直後に、「報告する判定」の列と、「この報告でのリスクの増え方・予想値」を、確定前にプレビューで出す。
- 【中】監査リスクのメーターに、60の目盛りの数字と、「ここで監査の予兆」の注記を付ける(白い印の意味が分からなかった)。
- 【中】「整合性リスク -10」と日報に出るときは、「(0 → 0)」のように、前後の数字も出す。
- 【中】「報告と監査の記録」に、どの指令についての報告か、どの方針かを出す(今は「第4季 正確に報告」だけ)。
- 【低】最終報告書2ページ目の、学習目標の枠とページ送りボタンの重なりを直す。
- 【低】優先順位が春にしか変えられないことを、第1ターンの運転ページに目立つように出す(今はマニュアルと切替器の「(固定)」表示のみ)。
