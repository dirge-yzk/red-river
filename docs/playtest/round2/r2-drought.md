## 3. 最終結果
- ランク C、総合 55%。
- 指標の評価(重み): 農業用水の充足度 44%(×2、供給14,258/需要32,487) / 生活・産業用水 100%(×1) / 環境流水の達成度 91%(×2、最低基準を満たしたのは 8/12 ターン) / 地下水の残存 30%(×1、貯留量は開始時の42%、揚水コスト上昇2区域) / 財政の健全性 100%(×1、最終残高3,796、最低残高705)。
- 総合は重み付き平均だが、最も低い指標+25%を超えない(農業44%なので上限が約69%になる)という説明が出ていた。
- 学習目標の要点:
  1. 水収支: 降水237,366 WU のうち蒸発散76%、用水供給16%、下流流出12%、貯留増減-4%。収支の残差は最大 7.3E-012 WU。
  2. 地下水のストック性: 貯留量は開始時の42%に。涵養5,086に対して揚水8,461、河川への湧出10,484。
  3. 配分のトレードオフ: 農業44%、生活100%、環境は8/12ターンで最低基準を達成。最も満たせなかったのは農業。
  4. 情報の価値: 調査2回(1,000)。終了時の推定誤差は、調査した区域で平均12%、未調査の区域で平均25%。
  5. 不可逆性: 上流山地・森林と中流農地で貯留量が閾値を下回り、揚水コストが恒久上昇(揚水費合計1,184)。
- ターン別の最終表(農業 / 環境 / 最低基準 / 残高): 春1 0%/53%/×/1,960、夏2 0%/64%/×/988、秋3 100%/100%/○、冬4 100%/100%/○、春5 63%/100%/○/2,234、夏6 30%/84%/×/741、秋7〜冬8 100%/100%/○、春9 100%/100%/○/2,574、夏10 38%/90%/×/3,160、秋11 83%/100%/○/3,743、冬12 100%/100%/○/3,796。
- 費用と収入: 用水の収入7,280、費用7,284(調査1,000/建設1,500/投資3,200/維持400/揚水1,184)。

## 4. 詰まった点・分かりにくかった点
- **スライダーの刻みと上限**: 農業・生活の取水目標スライダーは50WU刻みらしく、需要が刻みで割り切れないと右端でも需要に届かない(例: 生活の需要2,640に対し最大2,600、農業の需要2,940に対し最大2,900)。右端をクリックしても需要100%にならず、「満たさない設定」になるのが分かりにくい。実際に生活は2,600でも充足率100%と表示されたので害は小さいが、設定値と需要がずれる理由は画面に説明がなかった。
- **揚水上限の効き方**: 「揚水は河川水で足りない分にだけ使われる」の説明を読んでも、生活用水を井戸で賄うには「河川の目標」を下げる必要がある、とは最後(ターン12)まで気づかなかった。もっと早く知っていれば、夏の環境流水を守る手が増えた。
- **優先順位の意味**: 「水が足りないときは下の項目から削られる」と書いてあるが、環境流水は取水ではなく「取水後に下流に残る量」なので、実際は「生活→農業が先に取られ、環境は残り」に見える。ターン1の結果(農0%で環境も53%)を見て、環境を2位にしても生活が先に取るので環境は守られないと理解した。説明が欲しい。
- **結果カードの操作**: 長いカードの下に青ボタンが固定されており分かりやすかった。ただし最終結果は開いた時点で一番下の「学習目標」付近にスクロールされていて、先頭(ランク)を読むには上へスクロールが必要だった。
- 取水点の地図ラベル「前季の利用可能量」と、今季の見込み(利用可能量の範囲)の違いが最初は紛らわしかった。
- 誤クリックは特になし。

## 5. 不具合に見える挙動
- **森林の地下水閾値割れ(ターン10)**: 上流山地・森林には井戸がなく、私は一度も揚水していないのに、ターン10の結果で「上流山地・森林の地下水が閾値を下回りました。揚水コストが恒久的に上昇します」と出て、最終結果でも「揚水コスト上昇2区域」として地下水スコアを下げた。井戸のない区域に揚水コスト上昇が付く意味が分からない。画面の推定値は6,800(開始時)だったが、最終結果のグラフでは実際の値は最初から約2,500で、未調査のまま推定が+65%ずれていた。つまり実際は最初から閾値付近だった可能性がある。自然な渇水の流出でも閾値割れが起きるなら、プレイヤーが防げない。
- 揚水スライダー下の推定表示(「今季末の推定貯留量」)は、ターン11では上限250で4,085と出て、翌ターン開始時の推定も4,085で一致した。ターン12では上限0でも3,881(閾値4,000未満)と出た。つまり乾燥した冬は何もしなくても閾値付近まで下がる。
- 期待と異なる点: ターン11で揚水上限を250にしたため、秋の農業は83%。農業の需要が1,764に対し、河川で1,214しか取れず、井戸も250のみ。

## 6. 難易度の感想
- **4 / 5(やや難しい)**。
- 根拠: 春・夏の少雨と蒸発散で、取水点の利用可能量が需要を大きく下回る(夏は取水量3,000〜4,500に対し、農業+生活の需要が7,000〜8,500)。農業・環境・生活を同時に満たすことはできず、必ず何かを捨てることになる。夏3回のうち農業は 0%/30%/38%。環境も夏は64%/84%/90%で最低基準割れ。一方、秋・冬は余裕があり、行動の選択肢は少なく(概査・試掘・井戸・浸透改善・灌漑効率の5種類、1ターン1つ)判断自体は迷いにくい。
- 情報は概ね足りたが、足りなかった点は次のとおり。(a) 未調査の区域の推定が大きく外れること(森林は+65%)。(b) 夏に「どれだけ配分すれば最低基準を満たせるか」を示す明示的な計算がない。(c) 農業と環境のどちらを捨てるべきかを、ランク(重み×2)から判断できる情報が、結果が出るまで画面になかった。
- 難しさの大部分は、夏に農業を犠牲にするしかない構造にあり、これはシナリオの趣旨(農業と環境の対立)どおりだと思う。ただ、自分のプレイでは「どう工夫しても農業が44%程度」で、ランクCの上限が見えてしまった。

## 7. ほしい機能・改善案
1. (高) **配分のシミュレーション表示**: 「この設定だと農業X%・環境Y%になる見込み」を、予報の下限・中央・上限で表示してほしい。いまは取水点の利用可能量の範囲と目標しか出ず、自分で引き算している。
2. (高) **未調査区域の推定の根拠や、実際との差の目安**: 森林の推定が+65%も外れていたのは、最後の最終結果まで分からなかった。調査の優先度を判断できる情報(推定がどれだけ怪しいか)がほしい。調査費200は安いので、全区域を調べればよかったと終わってから気づいた。
3. (高) **ランクの重みを最初から見せる**: 「農業×2、環境×2、他×1。最低指標+25%が上限」は、最終結果まで読めなかった。方針を決めるときに知りたい情報。
4. (中) 優先順位の説明に「環境流水は取水後に下流へ残る量なので、優先順位は取水の順番を決める」という説明を足す。
5. (中) スライダーの刻みを需要に合わせる(右端=需要ぴったり)。
6. (中) 井戸のない区域に付く「揚水コスト上昇」の意味の説明。
7. (低) 結果カードの先頭が見えるように、最終結果を開いたときは先頭に位置させる。

## 8. もう一度遊ぶなら
- 変える。理由: 振り返りで分かった次の点を活かせるから。
  1. 序盤(ターン1)に、中流農地だけでなく森林・市街地も概査する(各200)。森林の推定が+65%も外れていたので、早めに調べれば揚水の判断や閾値割れの警告を避けられた可能性がある。
  2. 夏は生活の河川目標を下げて井戸で賄い、環境流水の最低基準を守る(ターン12で効果を確認できた)。それを夏にも使うため、揚水の持続量を超えない範囲で、井戸を2本目(別区域)建てて分散揚水する案を試す。
  3. 春の優先順位は「生活→環境→農業」のまま。ただし農業が犠牲になる分、灌漑効率の改善を1年目の夏に前倒しする。
  4. 試掘は早めに(ターン1か2)。貯留量の推定が下方修正されることを早く知り、2年目の夏に過剰揚水しないようにする。

## 9. 判断に使えた表示・使えなかった表示
### 役に立った
- 「今季の見込み(目安)」: 取水点の利用可能量の範囲、取水目標、下流へ流れる量、環境流水の最低基準、および赤字の警告(「最低基準を下回る見込み」「農業が届かない」)。毎ターン最初に見て判断した。
- 揚水上限の下に出る「このまま汲むと今季末の推定貯留量は約X(閾値4,000)」と、閾値割れの警告。揚水を絞る判断に直接使えた(ターン11)。
- 結果カードの「河川水の流れ」と「降水の行き先」、期末残高の内訳。
- 概査・試掘の結果カード(推定の幅が狭まる)。試掘で貯留量が大きく下方修正された。
- 各区域のカードの土壌水分バー。

### 役に立たなかった、または分かりにくかった
- 地図の区域カードの「地下水(推定) 約X WU (±N%)」: 未調査だと誤差が大きく(森林は+65%外れ)、これを信じると危ない。±N% は幅としては分かるが、偏りの方向が分からない。
- 「持続的揚水量(推定)」: 概査では1,261だったが、試掘後は976。概査の段階では高すぎる値だった。
- 区域の「流出係数」「土壌保水容量」などの数値は、効果をうまく判断に使えなかった(浸透改善の効果が分かりにくい)。
- 浸透改善の説明「年に約2,061 WU が浸透・涵養へ回る目安」: 実際に川の水が減ったのか、涵養が増えたのか、結果から読み取れなかった。
- 結果の「降水の行き先」に出る「蒸発散」などの大きな数字(夏は蒸発散34,420など)は、判断には使えなかった。

## 10. 遊びごたえ
- 工夫の効果はあった。ただし限定的。
- 根拠: 初期設定のままなら生活を最優先にせず、農業が先に取られていたはず(未検証)。優先順位を生活→環境→農業にし、井戸と灌漑効率改善を入れたことで、秋・冬は全項目100%を保てた。一方、夏は3回とも農業が0〜38%、環境が最低基準割れ(夏は64%/84%/90%)で、これは打ち手が無い。井戸の持続的な揚水量が1,000前後なので、夏の需要(農業5,000前後)には桁が足りなかった。
- 「何もしなくても良い結果になる」ことはない。春の概査と夏の井戸建設を飛ばすと、農業が全く賄えなかったはず(未検証)。
- 最終的にランクCだったので、もっと上を狙うには、環境流水の最低基準割れ(4ターン)を減らす工夫が必要だった。それはターン12の「生活を井戸で賄う」方法を夏に使うことで可能だったかもしれない(未検証)。それは地下水の閾値割れとトレードオフになる。
