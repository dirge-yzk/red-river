  - 試行2: ui.sh stop で止めて再起動。行動を何も選ばず既定値のままで進行ボタンを押したが、同じ症状。約3分(CPU時間 約3分)待っても変化なし。

  - 原因は不明(内部資料は見ていないので推測しません)。このシナリオ+シード16の最初の季節計算で止まる、または非常に時間がかかるように見えます。
