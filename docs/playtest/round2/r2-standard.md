## 3. 最終結果

- ランク B、総合 70%。
- 各指標の評価(重みはすべて ×1):
  - 農業用水の充足度 87%(供給 27,022 / 需要 30,940 WU)
  - 生活・産業用水の充足度 89%(供給 20,832 / 需要 23,400 WU)
  - 環境流水の達成度 99%(最低基準を満たしたのは 11/12 ターン)
  - 地下水の残存 45%(貯留量は開始時の42%、揚水コスト上昇 1区域)
  - 財政の健全性 100%(最終残高 3,497、基準 3,500、最低残高 800)
- 画面の注記: 総合は重み付き平均だが、最も低い指標 +25% を超えない。片方だけ最大化しても高ランクにはならない。
- ターンごとの推移表(最終画面): 農業は第6夏92%、第9春77%、第10夏37%、他は100%。生活・産業は第2夏の3%以外すべて100%。環境は第10夏のみ88%で基準割れ。
- 費用と収入: 用水の収入 8,777、費用 9,080(調査1,200 / 建設3,000 / 投資3,200 / 維持480 / 揚水1,200)。
- 学習目標の振り返りの要点:
  1. 水収支: 12ターンの降水 262,388 WU は、蒸発散79%、用水供給18%、下流端からの流出12%、貯留の増減 -9%。収支は全ターンで一致(最大残差 5.5E-012 WU)。
  2. 地下水のストック性: 貯留量は開始時の42%。涵養 5,644 WU に対し揚水 9,022 WU、河川へ 14,377 WU が湧き出した。
  3. 配分のトレードオフ: 最も満たせなかったのは農業用水(87%)。優先順位は「生活・産業→環境→農業」。
  4. 情報の価値: 調査は3回、費用1,200。終了時の推定誤差は、調査した区域で平均4%、未調査の区域で平均33%。市街地は第9ターンまで調べず、もっと早く調べるべきだったと指摘された。
  5. 不可逆性: 中流農地で貯留量が閾値を下回り、揚水コストが恒久的に上昇(揚水費の合計 1,200)。

## 4. 詰まった点・分かりにくかった点

- 【方針画面・井戸建設の効く時期】井戸のボタン下に「完成した次の季節から揚水できる」と書いてあったのに、読み落として第2夏に建てた。結果、その夏は生活・産業が3%になった。説明文が小さく灰色で、赤警告を見て焦っていた初見の私は気づかなかった。(解決: 次ターンから効いたので理解)
- 【方針画面・スライダー】生活・産業用水の河川目標スライダーは、需要より少し低い値(例: 需要1560で1550、需要2640で2600)で止まり、右端をクリックしても需要ぴったりにならないことがあった。結果は充足率100%だったので実害はなかったが、「なぜ需要と違うのか」は分からなかった。右端のクリックが1回で効かないこともあった(第9ターン、2回目で1800になった)。
- 【方針画面・設定の引き継ぎ】「設定は次の季節に引き継がれます」と書いてはあるが、冬に生活の河川目標を0にした設定が春にも残っていて、春の画面を開いてから気づいた。気づかなければ生活用水に河川の水が使われないままだった(実際は地下水で足りたか不明)。
- 【方針画面・優先順位】▲▼を押すと一つずつ入れ替わるので、「生活を1位、環境を2位」にするのに▲を3回押した(最初の2回で「生→農→環」になり、環境を戻すため1回追加)。途中の状態も画面に出るので誤解はなかったが、手数が多く感じた。春だけ変更できる点は、赤字の注記で分かった。
- 【揚水上限の意味】「持続的揚水量を超えています」「期末の推定貯留量は約○○(閾値4000)」の赤警告は分かりやすかったが、第10ターンは上限を950にしても閾値割れと出て、「どうしても避けられない」のか、何を変えれば避けられるのかが画面から分からなかった(結局、避けられないと判断して上限を1650に戻した)。
- 【揚水が使われる順序】「揚水は河川で足りない農業・生活産業の用水にだけ使われます」と書いてあるが、環境流水のために揚水を使うには「生活の河川目標を下げる」という間接的な操作が必要だった。これは冬(第8・12)に試行錯誤で見つけた。第10夏は優先順位が「生→環→農」でも環境が基準を割ったが、その理由(生活が河川から先に取る)を理解したのは結果を見たあと。
- 【最終結果画面】開いた直後、カードがスクロールの途中(指標の評価の下あたり)で始まっており、ランクの表示が見えなかった。一番上までスクロールして初めて「ランクB(総合70%)」を確認した。
- 【結果カード】カードが長く、財政・水の流れ・降水の行き先は毎回スクロールが必要だった。重要な行(充足率)は最初の画面にあるので、実害は小さい。
- 【結果カード背面】カードの背後に次ターンの方針画面が見えているが、カードに隠れて半端に見え、ぼんやりして邪魔に感じた(気にはならなかった)。
- 誤クリック: 特になし(▲の押し方に3回かかったのは操作の問題)。

- 生活・産業用水の河川目標スライダーを右端クリックしても、需要ぴったり(例 1560)にならず 1550 で止まる。操作: 右端をクリック → 実際: 1550 のまま → 期待: 1560(需要と同じ)。刻みが50単位なのかは画面から分からない。
- 第9ターン: 生活・産業用水スライダーの右端(x=1161)をクリックしても値が変わらず、少し内側(x=1148)をクリックして1800になった。右端のクリック判定がシビアに感じた。
- 方針画面の「今季の見込み」と実際の結果は、第9・第10ターンの期末推定貯留(4056、2203)は結果の推定値とぴったり一致しており、食い違いはなかった。

## 7. ほしい機能・改善案

1. (高)井戸建設の説明に「今季は使えません。次の季節から」を赤字か太字で目立たせる。私は第2夏に読み落としてペナルティを受けた。
2. (高)環境基準を守るための方法(生活・産業の河川目標を下げて地下水で補う)を、赤警告の近くにヒントとして出してほしい。私は冬に試行錯誤で見つけた。
3. (中)設定が次の季節に引き継がれることを、引き継がれた値の横に「前季から引き継ぎ」と小さく表示してほしい(第9春に0のまま気づいた)。
4. (中)優先順位の入れ替えに、「1位にする」ボタンかドラッグ入れ替えがあると手数が減る。
5. (中)最終結果画面を開いたとき、一番上(ランク)から表示してほしい。
6. (中)閾値割れが避けられないと見込まれるとき、「どうしても避けられません」と明示するか、揚水を0にした場合の見込みも表示してほしい。
7. (低)結果カードの重要な数字(充足率・環境流量・残高)を、スクロールしなくても一画面に収めてほしい。
8. (低)渇水の可能性(気象カードの出やすさ)を、年初に目安として見られるとよい。
