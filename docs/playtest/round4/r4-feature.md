## 3. 最終結果
- ランク S / 総合 97%。プレイ時間 8.4 分(目安 15〜25 分)、方針決定は平均 32 秒(目安 45〜90 秒)と表示。
- 農業用水の充足度 86%(供給 27,564 / 需要 32,060)
- 生活・産業用水の充足度 100%(22,061 / 22,061)
- 環境流水の達成度 100%(最低基準を 12/12 ターンで満たした)
- 地下水の残存 100%(貯留量は開始時の 123%、揚水コスト上昇区域 0)
- 財政の健全性 100%(最終残高 11,168、基準 3,500、最低残高 800)
- 総合は「重み付き平均だが、最も低い指標 +25% を超えない」と説明あり。
- 用水の収入合計 9,337 / 費用合計 10,169(内訳: 調査 200 / 建設 1,500 / 投資 7,900 / 維持 320 / 揚水 249)。
- 学習目標の振り返り:
  1. 水収支: 12 ターンの降水 304,887 WU は 蒸発散 69%、用水供給 16%、下流端流出 12%、貯留増 4% に配分された。浸透・涵養は貯留の場所を移すだけで流域外への損失ではない。残差は最大 1.1E-11 WU。
  2. 地下水のストック性: 貯留量は開始時の 123%。涵養 25,223、揚水 2,727、湧出 19,194、河川→地下水への浸透 3,864 WU。地下水は涵養と揚水・湧出の差が積み重なるストック。
  3. 配分のトレードオフ: 農業 86%、生活 100%、環境は 12/12 ターン。最も満たせなかったのは農業。最後の優先順位は「生活産業 → 環境流水 → 農業」(最初から変えていない)。
  4. 情報の価値: 調査は 1 回(200)。観測井戸は中流農地と市街地。終了時の推定誤差は、調査した区域で平均 1%、未調査の区域で平均 8%。
  5. 不可逆性: どの区域も閾値を下回らず、揚水費の合計は 249。
- 「推定と実際の地下水貯留量」のグラフ(青: 推定、赤: 実際)があり、上流森林は最後まで推定幅 ±43% のまま(終了時の推定は実際より +5%)、中流農地は −1%、市街地は −5%、下流湿地は ±45% のまま −15%。

## 4. 詰まった点・分かりにくかった点(新機能ごと)

### 貯水池の建設と操作(森林の区域タブ → 今季の方針の操作スライダー)
1. 説明で分かったか: 分かった。建設後の森林タブの文は「取水点の上流に、5,000 WU の貯水池をつくる。河川水が豊かな季節に貯め、不足する季節に放流できる(夏は蒸発で貯留量の 6% を失う)。操作は「今季の方針」タブ」。スライダー下の説明「右へ動かすと河川水を貯めます(その分、取水と下流に回る水が減る)。左へ動かすと放流します」と、その下の「見込み: 蒸発で X WU 失い、貯める/放流 → 季節末の貯水量 Y WU」の1行が特に分かりやすく、動かすたびに結果が数字で確認できた。
2. 効果を感じたか: 数字の動きは確認できた。冬に貯めると取水点の利用可能量が下がり(ターン4: 6,532 → 3,581)、夏に放流すると上がった(ターン6: 利用可能量 8,347。予報の範囲 6,102〜8,398 の上端)。ただし農業の充足率が良くなったかは、放流なしの場合と比べていないので「分からなかった」。ターン10 は放流 2,150 としたが、農業は 100% で、放流しなくても足りていたかもしれない。
3. 費用に見合うか: この平年シナリオでは見合ったとは言えない。費用は約 2,000(推測、ボタンの金額を読めていない)。貯めた水は夏に蒸発で目減りした(ターン6 で 85、ターン10 で 190)。環境流水は 12 ターンとも 100% で、貯水池がなくても足りた可能性が高い。干ばつ系のシナリオなら価値が出ると思うが、試していない。
4. 分かりにくかった点: (a) スライダーの「ゼロ位置」が、貯水量によって動く。貯水量 0 のときは左端が「貯める 0」で、貯水量 1,421 のときは左端が「放流 1,400」、中ほどが「貯める 0」。初めて見たとき、ゼロの位置が探しにくかった。数値の表示(「今季の操作: 貯める 0 WU」)を見ないと位置が分からない。(b) スライダーのクリック位置と数値の対応が粗い(試した値は 1,450 / 1,800 / 1,400 / 2,150)。細かい調整ができるのか分からなかった。(c) 「今季の見込み」の「取水点の利用可能量」の範囲が、スライダーを動かすと変わるのかは、確認していない。(d) 貯水池は森林の区域に置かれる設定なのに、「取水点の上流」と説明されていて、地図上のどこにあるか分からなかった(森林カードに「貯水池 1,450 WU」と文字が出るだけ)。

### 観測井戸(区域タブ)
1. 説明で分かったか: 分かった。「完成した次の季節から、季節ごとに推定の幅が 40% ずつ狭まる(下限 ±5%)。調査より安く、時間をかけて精度が上がる」。
2. 効果: 推定の幅は実際に狭まった(中流農地 ±25% → ±15% → ±9% → ±5%。市街地は ±43% → ±26% → ±15%)。区域カードの「地下水(推定) 約 X WU (±N%)」の ±N が小さくなるのが目に見えて、効果は分かりやすかった。
3. 費用に見合うか: 費用 500。判断(井戸を建てる/揚水を絞る)が変わったという場面はなかったので、費用に見合ったかは分からなかった。市街地は終盤(ターン10)に設置したので、効果を使う場面がほとんどなかった。早く置くほど価値がある設計だと思うが、観測井戸だけで井戸の建設や試掘の代わりにはならない点が、説明にはなかった。
4. 分かりにくい点: 設置したターンの結果カードに「観測井戸: 推定の幅が ±25% から ±15% に狭まりました」と出るが、設置した季節ではなく次の季節の結果で出る、という関係が最初は分かりにくかった(説明の「完成した次の季節から」とは一致している)。

### 市街地の雨水利用・再生水
1. 説明で分かったか: 雨水利用は「生活・産業用水の需要を 12% 減らす。河川水や地下水を、ほかの用途へ回せる」。再生水は「供給した生活・産業用水(河川水)の 25% が下流へ戻り、環境流水を支える」。どちらも一文で意味は分かった。
2. 効果: 数字では確認できた。雨水利用: 夏の生活産業の需要が 2,640(ターン6)→ 2,323(ターン10)でちょうど −12%。再生水: 結果カードの河川水の流れに「再生水の還元」が出た(ターン8: 343 = 供給 1,373 の 25%、ターン9: 396、ターン10: 581)。ただし、体感として「結果が良くなった」とは言えない。
3. 費用に見合うか: 見合わなかった(雨水利用 800、再生水 1,000)。生活産業と環境流水は設置前から 100% で、水が足りなくなる場面がなかった。また、雨水利用で需要が減ると、水道収入(供給 1 WU あたり 0.20)も減るはずで、収入面では不利かもしれない(これは推測。確かめていない)。
4. 分かりにくい点: 再生水の「25%」の対象が「河川水で供給した分」である点は説明にあるが、地下水で賄った分は戻らないのか等は説明がない。再生水の還元は、環境流水が足りない年に使うものと想像するが、その場面は試していない。

### 井戸の増強(井戸のある区域)
1. 説明で分かったか: 「井戸の揚水能力を 1.5 倍にする(今は 1,800/季節)。ただし、汲みすぎると地下水が減る」。能力が 1,800 → 2,700 になったのは確認できた。
2. 効果: 感じなかった。能力が上限に達する場面がなく(農業の地下水の使用は 1,100 や 527 だった)、能力が足りなかったことが一度もない。
3. 費用に見合うか: 見合わなかった(700)。
4. 分かりにくい点: 増強したあとも「揚水上限」スライダーの値は 1,100 のままで、スライダーの位置が左にずれただけ。増強で何が変わったかは、「井戸の能力 2,700」の1行を読まないと分からない。

### 高効率ポンプ(今季の方針タブの下の方)
1. 説明で分かったか: 「完成した次の季節から、揚水費が 40% 下がる。たくさん汲む場合に元が取れる」。分かった。
2. 効果: 確認できた。揚水費は ターン5 は 0.12/WU(1,100 WU で 132)、ターン6 は 79(1,100 WU で 0.072/WU)、ターン11 は 38(527 WU で 0.072/WU)。40% 減になっている。
3. 費用に見合うか: 全く見合わなかった(費用 400 に対し、節約できたのは ターン6 と ターン11 の合計 約 74)。「たくさん汲む場合に元が取れる」とあるが、この平年シナリオでは揚水が少なく、元は取れない。どのくらい汲むと元が取れるかの目安が画面にあるとよい。
4. 分かりにくい点: 見た目は区域のボタンではなく「流域全体の施設」の中にあり、スクロールしないと気づきにくい(今季の方針タブの一番下)。

### 右パネルの「用語集」タブ
- 最初は開いた(ターン1)が、画像が読めなかったので内容を確認したのは終了後。内容は、WU、水収支、蒸発散、流出係数、土壌保水容量、浸透・深部排水(涵養)、湧出、地下水貯留量(ストック)、持続的揚水量、閾値・揚水コスト上昇、河川から地下水への浸透、取水点、環境流水、配分優先順位、充足率、概査・試掘、観測井戸、貯水池、雨水利用・再生水、灌漑効率・高効率ポンプ、できごと、総合ランク。
- 役に立ったか: 内容は短く分かりやすく、「河川から地下水への浸透」「閾値・揚水コスト上昇」「地下水貯留量(ストック)」が結果カードの言葉とそろっていた点が良い。ただし、ゲーム中に私が実際に用語集を見て判断を変えた場面はなかった(ターン1 の内容は読めていないので、そこで役立ったかは分からなかった)。
- 不足: 貯水池のスライダーの読み方(ゼロ位置の動き)、「取水点 前季の利用可能量」と今季の違い、「見込み」の計算方法は載っていない。ⓘ のマウスオーバーの説明は ui.sh でマウスが使えないため試せなかった。

### 方針パネル上部の「ここまでの評価(見込み)」棒グラフ
- 5本の棒(農業用水の充足度、生活・産業用水の充足度、環境流水の達成度、地下水の残存、財政の健全性)と、ランク・総合が出る。説明は「終了まで続けた場合の最終評価の目安です。いちばん低い指標に総合点が引っ張られます。地下水だけは、推定の値で計算しています」。
- 判断に使えたか: 部分的に使えた。ターン5 で最初に「ランク S / 総合 90%」と出て、農業用水の棒だけが 65% で短く、「農業を何とかしたい」と気づけた(だから灌漑効率の改善を選んだ)。総合の数字も、最も低い指標 +25% の上限(65 + 25 = 90)と平均の組み合わせで説明が付き、整合していた。
- ただし、ほとんど常に「ランク S」なので、行動を選ぶ決め手にはなりにくい。行動の前後でどれだけ変わるかも分からない(選んだ行動を反映した見込みは出ない)。
- 表示の問題: 右端の数字(%)がパネルの右端で見切れている(「65%」が「65」、「100%」が「100」、「83%」が「83」のように途中で切れる)。「生活・産業用水の充足度」のラベルも棒に接触している。毎ターン「方針」を最上部までスクロールして戻さないと見えない点も不便。

### 川の水が地下水に浸透する話(結果カード)
- 結果カードの「河川水の流れ」に「河川から地下水へ浸透: 272 WU(地下水位が低い区域ほど、川の水が地下水に吸われます)」と毎ターン出る(272、305、411、512、338、417、321、175、172 など)。最終結果の学習目標2 にも「河川から地下水へ 3,864 WU が浸透しました(地下水位が下がるほど、川の水が地下水に吸われます)」と出る。用語集にも「地下水位が低い区域では、川の水が地下水に吸われます(農地・市街地)。地下水を汲みすぎると、川の流れも減ります」とある。
- 理解できたか: 「地下水位が低いほど川の水が吸われ、汲みすぎると川の流れが減る」という方向は理解できた。取水点の利用可能量の式の説明(地表流出 + 地下水の湧出 − 浸透、に貯水池の操作を加えた量)にも位置づけがあり、水収支は一貫していると思う。
- 分からなかった点: (a) 浸透した水が最終的にどこへ行くのか(その区域の地下水の増加になるとは思うが、画面には出ない)。(b) 浸透量の大小の原因。ターン7 の 512 が大きい理由(夏のあとで地下水が減ったから?)は推測で、画面では確認できなかった。(c) 浸透が多いことが良いのか悪いのか。取水点の利用可能量を減らす項目なので、悪いもののように読めるが、地下水が回復していることでもあり、評価が分からなかった。(d) 「浸透・涵養」「河川から地下水への浸透」が別の言葉として出てきて、混同しやすい。

- 評価メーターの右端の %(上記)が見切れている。見た目の不具合。
- ターン7 で、スライダーを操作した直後に位置を確認するために地図付近をクリックした際、意図せず下流湿地の区域が選択されて右パネルのタブが切り替わった(私の誤クリック。ただし、パネルの切り替えは仕様どおり)。
- 「今季の見込み」の赤い警告「降水が少ない側では、河川水が足りず 農業 X WU が目標に届きません(井戸があれば地下水で補います)」は、井戸が既にあっても毎回出続け、実際は補えて 100% になることが多かった。警告として過剰に見える(ただし井戸の能力を考慮しているかは確認していない)。
- 貯水池の建設・観測井戸などの「完成は次の季節から」ルールは、ボタンの説明に明記されているので、食い違いではない。

## 6. 難易度の感想
- 5段階で 2(やや易しい)。根拠: 初期資金 9,000 で、新機能を全部買っても残高が 11,168 まで増えた(最終収入 9,337 に対し費用 10,169。残りは交付金)。生活産業と環境流水は全ターンで 100%、農業もターン3 以降はほぼ 100%(ターン5 の 91%、ターン6 の 95%、ターン11 の少雨でも 100%)。「最終的に何を優先すべきか」で悩む場面がなかった。ただし、`--funds 9000` の指定は新機能を試すための特別条件で、通常のゲームの難易度ではないはず。
- 選べる行動はたくさんあるが、判断材料(予報の範囲、今季の見込み、スライダーの見込み1行)は足りていた。逆に「どの施策が効くのか」を決める根拠(例: 費用に対する見込み効果)が画面にないのは、新機能を試す私には少し困った。

## 7. ほしい機能・改善案
1. (高)評価メーターの右端の数字の見切れを直す。
2. (高)貯水池スライダーのゼロ位置の目印(「0」の印や、中央を境に「貯める/放流」と書いた目盛り)がほしい。
3. (高)各施設に「いつ元が取れるか」「この条件で効く」といった目安を出す(特に高効率ポンプ、井戸の増強、雨水利用、再生水)。今は費用だけ見て「効果があったか」を自分で確認するしかなかった。
4. (中)選択中の行動を反映した「ここまでの評価(見込み)」(行動の前後比較)。
5. (中)河川から地下水への浸透について、その区域の地下水の増加にどう反映されたか、結果カードか用語集に1行ほしい。
6. (中)貯水池の位置を地図上で示す(貯水池アイコン)。
7. (低)井戸の増強後に「揚水上限」スライダーの上限を自動で伸ばす、または説明する。

## 8. もう一度遊ぶなら
- 序盤(ターン1〜3)に主要行動を3つ使い切るのではなく、概査 1 回 → 農業に効く施策 → 貯水池、と効果が大きそうな順に使う。今回は雨水利用・再生水・井戸の増強・ポンプが効果を実感できず、貯水池や観測井戸も「やった」感が薄かった。
- 渇水シナリオや乾燥地シナリオでも、同じ新機能を試して、費用に見合うかを確かめたい。平年では必要性が見えにくい。
- 評価メーターで一番低い指標を毎ターン確認して、そこに効く行動だけを選ぶ。

## 9. 判断に使えた表示・使えなかった表示
- 使えた:
  - 貯水池スライダー下の「見込み: 蒸発で X 失い、貯める/放流 → 季節末の貯水量」の1行。
  - 区域カードの「地下水(推定) 約 X WU (±N%)」の ±N(観測井戸や調査の効果が見える)。
  - 結果カードの「河川水の流れ」と「降水の行き先」の数字(収支が一致しているという確認も安心感があった)。
  - ここまでの評価の棒(農業が最低だと気づけた)。
  - 揚水上限スライダー下の「持続的な揚水量」「今季末の推定貯留量(閾値 4,000)」。
- 使えなかった / 意味が分からなかった:
  - 「今季の見込み」の「取水後に下流へ流れる量」が範囲で出る点(貯水池の操作が反映されるのか分からない)。
  - 「前季の水収支(WU)」の表(区域タブの下の方)。ターン6 の市街地は「浸透 1,200 / 実蒸発 1,273 / 土壌水分の変化 −73」と出たが、何を判断に使うのか分からなかった。
  - ⓘ のツールチップ(マウスが使えず確認できなかった)。

## 10. 遊びごたえ
- 工夫した分だけ結果が良くなったとは言えない。ターン5 の時点で既にランク S の見込み(90%)で、そこから総合 94 → 96 → 97% と上がったが、その上昇は農業の充足率の自然な回復による部分が大きいように見える(新機能の効果を切り分けられていない)。最初の設定のまま何もしなくても S になったかどうかは、試していないので分からなかった。
- 新機能のうち、効果が数字として見えたのは 観測井戸(推定幅の縮小)、高効率ポンプ(揚水費 −40%)、雨水利用(需要 −12%)、再生水(還元 25%)、貯水池(貯水量と取水点の利用可能量の増減)で、「機能が説明どおり動く」ことは確認できた。一方、「結果が良くなる」ことは確認できなかった。
- 学習目標の振り返り(水収支、ストック、トレードオフ、情報の価値、不可逆性)は、画面の数字と一致していて、読み物として良かった。
