# プレイテスト記録シート

仕様書 14 章・16 章の完成条件「少なくとも3人にプレイテストを実施し、詰まった点・学んだ点を記録する」「1プレイが15〜25分程度で完了する」のための記録用シートです。

**状況: 未実施です。** このシートはテスト実施者(人間)が記入します。開発側のテストでは代替できません。

## 準備

```sh
# プレイヤーごとにログを残す。方針決定の所要時間が標準エラーに出る
dotnet run --project src/WaterGame.App 2> playtest-<名前>.log
```

- ログには毎ターンの水収支の残差(`[balance]`)と、方針決定に要した秒数(`[time] turn=N decision=…s`)、最後に全体の所要時間(`[time] total=…min`)が出ます。
- 最終画面にも、プレイ時間と方針決定の平均秒数が出ます (目標: 1プレイ 15〜25 分、1ターンの方針決定 45〜90 秒)。
- 計測は「はじめる」を押した時刻からです。結果カードを読む時間は、方針決定の秒数には含みませんが、全体の所要時間には含みます。
- 最初のプレイでは操作を教えず、遊び方の画面だけで始めてもらってください。詰まった所が見えます。
- 可能なら、同じシードで別の方針を試してもらいます (最終画面の「同じシードで再挑戦」)。気象と地下水が同一なので、方針の違いが比べられます。
