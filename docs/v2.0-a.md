# 計画経済版 v2.0-a (指令・上司の信頼・計画達成度)

設計書「ソ連計画経済版 設計書 (v2.0改訂案)」の垂直スライス v2.0-a を、v1.2 の上に実装した。

## 方針 (確認済み)

- 既存のシナリオ (入門を除く5つ) に、指令の層を重ねた。別のモードにはしていない。入門には、指令を載せない。
- 水文学のコアには手を入れない。指令の層は、結果を読むだけで、水量・地下水・河川流量を変えない。影響が及ぶのは、上司の信頼を通じた年度の交付金と、達成報酬の補助金 (財政) だけ。
- 既存の「できごと」(交付金の削減、停電、需要の急増) は残し、指令とは並存させる。できごとは天候・経済の外乱、指令は中央からの要求。
- 既存の貯水池・観測井戸・拡張などの設備も、そのまま残す。

## ルール

- 指令の列は、シナリオから固定で決まる (v2.0-b で、乱数をやめた。期間は 3・2 ターンの繰り返し、種類と目標の位置は決まったパターンの繰り返し)。
- 最初のターンから、2〜3ターンおきに発令し、期限は次の発令の直前 (最後の指令は終了まで)。最後のターンだけの指令は出さない。
- 種類: 生産ノルマ (綿花の増産 = 農業用水の充足率) と、工業用水の供給 (生活・産業用水の充足率)。農業の需要がない期間には、綿花の指令は出さない。
- 目標: 期間の充足率 (河川水と地下水の供給量の合計 / 需要量の合計) の目標。シナリオごとの範囲から、決まった位置 (下端 → 中央 → 上端 → 1/4 → 3/4 の繰り返し) で選ぶ。最初の指令は、準備の時間がないので、範囲のいちばん下。
- 判定: 期限のターンの結果まで含めて、充足率 / 目標 で判定する。1以上=達成 (補助金 = 年度の交付金の 0.4 倍、上司の信頼 +8) / 0.9 以上=一部達成 (変化なし) / 0.9 未満=未達 (信頼 −10)。
- 上司の信頼は 0〜100 で、始まりは 50。年度の交付金に、0.8 + 0.4 × 信頼/100 を掛ける (信頼 50 で標準)。
- 計画達成度 = 判定済みの指令の min(1, 充足率/目標) の平均。流域の実態 (従来の5指標と総合ランク) とは、混ぜない。

| シナリオ | 目標の範囲 |
|---|---|
| 平年・市街地拡大 | 0.90〜1.00 |
| 渇水 | 0.85〜1.00 |
| 乾燥地・長期の試練 | 0.75〜0.95 |

## バランスの測定 (簡易プレイヤー、12シード)

「実態最良」は、流域の実態の総合点が最良の設定 (指令を気にしない)。「達成度最良」は、計画達成度が最良の設定。数字は、判定された指令の結果の割合。

| シナリオ | 実態最良: 達成 / 一部 / 未達 | 達成度最良: 達成 / 一部 / 未達 | 実態の総合点の差 |
|---|---|---|---|
| 平年 (0.90〜1.00) | 31% / 14% / 55% | 72% / 14% / 14% | −0.004 |
| 市街地拡大 (0.90〜1.00) | 31% / 16% / 53% | 78% / 3% / 19% | −0.007 |
| 渇水 (0.85〜1.00) | 10% / 34% / 55% | 52% / 12% / 36% | −0.019 |
| 乾燥地 (0.75〜0.95) | 36% / 16% / 48% | 34% / 28% / 38% | −0.005 |
| 長期の試練 (0.75〜0.95) | 39% / 14% / 48% | 30% / 32% / 38% | −0.013 |

- 指令を達成しに行くと、流域の実態の総合点は下がるが、その差は小さい (0.004〜0.019)。この版では、指令と流域の実態の対立は、まだ弱い。対立を強めるのは、報告・監査・資材・非公式取引 (v2.0-b 以降) の役割で、この版では、数値を動かしていない。
- 設計書の未決事項 (報酬・ペナルティの大きさ、閾値など) は、すべて仮の値で、人間の試遊での確認が必要。

## テスト

`tests/WaterGame.Tests/V15Tests.fs`: 入門に指令がないこと / 指令の列の再現性 / 期間が隙間なく続くこと / 綿花の指令は農業の需要がある期間だけ / **指令の有無で、水量の結果が変わらない** / 判定の正しさと報酬 / 信頼が 0〜100 に収まり、期末残高が報酬を含めて一致すること / 交付金が信頼で変わること / 計画達成度の計算。

## 画面

- ヘッダー: 上司の信頼のメーターと数字 (入門にはない)。
- 右の盤の「指令」ページ (入門にはない): 指令書 (紙)、ここまでの充足率のメーター (赤い針が目標)、計画達成度のメーター、判定済みの指令の一覧。
- 地図の下の表示灯: 届いた指令と、来季の指令の予告。
- 運転日報: 1ページ目の上に、ハイライト (なぜそうなったかと、判定された指令の結果)。2ページ目の財政に、達成報酬。
- 最終報告書: 1ページ目に、流域の実態・計画達成度・政治的評価の3つ。2ページ目に、計画指令の結果の表。

## AIテスターの結果 (第6回、`docs/playtest/round6/`)

平年 (シード 401) と、渇水 (シード 402、指令を最優先) を、12ターン遊んだ。どちらも、最初の設定 (平年 0.85〜1.00、渇水 0.80〜0.95、信頼 +10/−8) では、**指令を5件とも達成**し、信頼が 100 に達した。簡易プレイヤーより、人間 (AI) のほうが、優先順位や貯水池を使って、うまく達成できた。そこで、目標を上げ (上の表)、信頼の動きを、達成 +8 / 未達 −10 に変えた。この設定での、AIテスターによる確認は、まだしていない。

| 指摘 | 対応 |
|---|---|
| 日報ハイライトの説明が、実績と逆に読める (生活・産業 94%、農業 71% なのに「生活・産業が不足」) | 不足した用水と、その充足率を並べて書く文面に変更 |
| 指令の期限のターンが、運転ページから分からない | 地図の下の表示灯に「今季が期限の指令」を追加 |
| 期限までの途中経過が、日報に出ない | 日報のハイライトに「進行中: ここまでの充足率」を追加 |
| 補助金 280 が、何の額か分からない | 指令書に「年度の交付金の4割」と明記 |
| 日報1ページ目と2ページ目などで、同じ情報が重なる | 日報の各ページの役割 (ハイライト / 計器・計画と実績 / 用途別・財政) の違いとして据え置き |
| 指令の「期限までの需要の目安」が冬に 0 になる | 農業の需要がない季節なので正しい。説明は未対応 |
| 信頼は、最後の春以降は交付金に効かない | 設計上の性質。後続の版 (監査・更迭) で、信頼の用途が増える |
| 一部達成・未達の画面を、テスターが見ていない | 未確認 |

> **v2.0-b での変更:** 乱数の排除に伴い、指令の列と目標の決め方を固定のパターンにした (「厳しい指令になる確率」は廃止)。上の測定値は、乱数のあった版のもので、参考値。
